# 待确认项

以下是证据边界，不是前端可以自行选择的业务算法。原型中对应位置显示“待核验 / 待接入 / 示例”，没有补造公式；前端设计工作未因此停下。

| # | 待确认 | 原型中的处理 |
| --- | --- | --- |
| 1 | Craft&Fresh、Sheet1 的业务角色及是否有其他字段依赖 | 覆盖表标“角色待确认”，保留回查入口 |
| 2 | 年度/月/周、财年目标、半月预测、海运期末/月底库存、可售天数、变体依赖的逐字段公式与人工输入边界 | 仅 US 的 J=HT/I、HX=(HS+HT)/(HO/7) 做实时示例；其余显示源值或“待接入” |
| 3 | 总销量各“全球”指标实际覆盖的国家/Listing | 总销量页顶部提示；演示月销量为独立虚构值，不由国家页加总 |
| 4 | 财年目标起止年份、目标形成与分摊、历史目标是否锁定 | 默认不对照；“假设对照”需手动选择，不计算完成率 |
| 5 | 发货计划如何对应已建货件、实际发货、部分执行，何时冲销 | 计划 / 已建待发 / 已发 / 接收差异分列；计划状态为示例 |
| 6 | 运营角色、记录负责人、正式更新确认人、历史修正人及并发冲突最终规则 | 演示身份 + 冲突模拟；明确标注不是权限 |
| 7 | 原表疑点、缺失月份、错误公式、未匹配商品的逐项复核流程 | 异常表列出原因、范围、来源与处理结果，提供跳转 |
| 8 | 变体比例分子引用的年度 | 演示按 2025 年合计，并标“引用年度待核验” |
| 9 | SA 部分月份标题的确切范围 | 演示为 2025 年 8—12 月，其余“无字段” |
| 10 | 各国运输天数 D1、加权系数等参数的真实取值 | 演示为示例参数（标注“示例”）|
| 11 | 2022/2023 年度字段在 US/CA/AU/UK 的确切列位置 | 字段清单 JSON 未随本包提供，界面不写列号 |
| 12 | “国内够发”（HW 国库充盈）原公式 | 显示源值；另有一列“演示核对（非原 HW 公式）” |
| 13 | 计划合计超出国内现货时的业务处理（拆分、优先级） | 只提示“超出现货 X”，不自动分配 |
| 14 | 新建批次的业务批次日与创建日期范围的默认值 | 更新流程中由人工填写 |
