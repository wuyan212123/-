# 状态说明：真实交互与设计占位

本原型只有前端本地状态。下表中的“真实交互”指在浏览器内实际可操作、状态会联动；**不代表**原公式已复现、数据已接入或多人服务已实现。

## 真实可交互（前端本地状态）

| 功能 | 说明 |
| --- | --- |
| 国家切换与视图切换 | 七国、八个视图；各国筛选、页码、排序独立保留；切换国家时沿用当前视图 |
| 表格 | 冻结 SKU/品名列、吸顶表头、表格内横向滚动、排序、分页、零值显示为空白（底层仍为 0） |
| 月/周历史 | 全年份同时展开；月份高亮；周按源周区年份、起止周、最近 8 周、全部已有周切换 |
| SKU 统一详情 | 七个分区与锚点、国家/Listing 切换、上一个/下一个、返回并恢复来源列表全部状态 |
| 全局搜索 | 工具栏浮层（键盘可选）、搜索页、精确优先、命中字段高亮、国家+负责人组合、多 SKU 粘贴、空结果恢复 |
| 运营人员视图 | 人员 × 国家矩阵、状态筛选、未分配入口、“当前筛选”小计（国内现货按 SKU 去重） |
| 编辑与联动 | 本次发货量 / AE 备货数量 / 备注 / 半月计划可编辑；US 箱数（J=HT/I）与补货后可售天数（HX）实时示例计算；SKU 计划汇总、国内现货核对、总销量 DL:EE 汇总实时更新 |
| 批次与在途 | 各国独立选择计入在途、全选、明确空选（=0）、恢复原范围；详情与国家页是同一份选择 |
| 保存 / 放弃 | 未保存计数条；保存只写本页内存，版本号 +1 并写入演示修改记录 |
| 冲突模拟 | “模拟同事修改同一记录” → 保存时出现版本冲突，逐条选择采用同事值或核对后覆盖 |
| 只读身份 | 切换为“查看者（演示·只读）”后所有输入禁用（这是演示，不是权限） |
| 更新流程模拟 | 文件纳入/用途 → 基准日与模式 → 预检（沿用/阻断/跳过/隔离）→ 变化预览 → 应用；可模拟“预检后版本变化” |
| 过程记录 | 数据更新与异常页可切换 14 张过程记录表（由演示数据推导，结构对应现有表格）|
| 主题与密度 | 跟随系统 / 浅色 / 深色；舒适 / 紧凑；侧栏收起（偏好存于本浏览器） |

## 设计占位（未实现）

| 项目 | 当前表现 |
| --- | --- |
| 登录、账号、角色权限 | “演示身份”下拉只切换输入可用性 |
| 多人同步、版本服务、通知 | 冲突由按钮模拟；从不显示“已通知同事/已同步” |
| 文件读取与导入、指纹计算 | 文件为占位名称；“添加本地文件”按钮禁用 |
| 数据库持久化与审计存储 | 刷新即重置；修改记录只在本页内存 |
| 原公式结果接口 | 非 US 的补货后天数显示“待接入”；月末/月底/可售天数为源值示例 |
| 计划状态机（草稿/已确认/部分执行） | 示例状态标签，规则待业务确认 |
| 采购相关 | 只展示国内采购在途与原表采购字段回查，无采购计算或下单 |

## 演示数据说明

`src/data.js` 用固定种子生成，覆盖：同 SKU 多国不同运营、同国同 SKU 两个 Listing、未分配负责人、缺报月份、年度与月合计差异、遗漏周、真实 0 销量、零分母/组外引用/#REF!/人工比例、缺装率、海外仓小计差异、国内字段空白、EU 多站重复库存、库龄重复 MSKU、原量 100 收 96/104/100、报 72 收 74（ERP 收发差异反号）、完整快照未列出核销 0、无原发货依据批次、未知 SKU 隔离、同批次双快照冲突、海外仓 SY 批次。运输天数、权重等参数为示例值，不是原表取值。
