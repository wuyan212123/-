# 设计说明

**核心布局。** 左侧为可收起的轻材质侧栏（工作台 / 汇总与计划 / 数据与核对三组入口），顶部常驻全局搜索（`/` 键聚焦）与“演示身份/密度/主题”控件，其下一条“逐模块来源日期”横条把销量、FBA、国内、AWD、货件、库龄各自的日期与“沿用旧周期/阻断”状态分开显示。默认进入**国家主表**：SKU 行是主体，七国用分段控件切换（AE 标“部分”、SA 标“简表”），同一张表内用八个视图切换综合总览、月历史、周历史、未来计划/目标、发货计划、批次与在途、库存明细、商品资料。SKU 与品名两列冻结，表头吸顶，宽表在表格自身容器内横向滚动。

**SKU 统一详情是一个完整页面而不是抽屉。** 顶部固定区包含“返回来源（带页码）”、上一个/下一个 SKU、国家切换（全部国家 + 有记录的国家）、同国多 Listing 选择和分区锚点；下面依次是总览、历史销量、未来计划/目标、发货计划、批次/在途、库存明细、资料/来源。每个面板标注数据层级（SKU 聚合层 / 国家层 / Listing 层 / 商品层），避免把共享国内库存与 Listing 数据混算。

**为什么适合进销存。**
- 一份状态，多处入口：计划量、备注、半月计划、批次选择、冲突状态都存在同一个状态对象里；国家页、人员页、搜索、发货计划、详情和总销量 DL:EE 汇总读写同一份数据，改一处其他入口同步。
- 同月比较优先：月历史固定“年份为行 × 1—12 月为列”，所有可用年份默认展开，点月份表头高亮所有年份同月（表头附文字“● 已高亮”）；“截至 10/11”只标在 2026×10 这一格；US/CA/AU/UK 的 2022/2023 单独成行标“仅年总量”。
- 数值语义不混：缺报“未提供”、源表“无字段”、期间“未发生”、源表旧期“空”、原公式“待接入”、真实 0 分开显示；负差异保留负号并标红，同时有“多收/少收”文字。
- 证据随手可查：列头副标题写源列（如 `HT列 · 人工`、`J=HT/I（局部已证）`、`BQ · 前3个完整月×权重`），可编辑的人工计划格有独立底色和图例，只读源值不可编辑。
- 视觉克制：材质只用于侧栏与工具栏，表格、输入、弹层使用实底；系统字体、等宽数字、细边线和轻阴影；状态同时用文字和图形表达；支持深色、紧凑密度与减少动态效果。

**与另一方案最显著的区别。** 不把业务拆成互不相连的模块：国家主表在一张表里用视图切换承载八类工作，SKU 详情是整页工作区（可同时容纳多年月矩阵、全部周与 20 期宽表），并配合“来源列表上一个/下一个”和精确返回（关键词、筛选、页码、排序、横向滚动位置都恢复），把“按国家/人员找商品 → 对比历史与计划 → 核对库存与批次 → 编辑计划”放在一条连续路径上。
