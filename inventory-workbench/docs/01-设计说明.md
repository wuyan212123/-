# 设计说明

> 2026-10-14 第四版：增加列配置、年份多选、版本记录，重排运营人员视图（见文末“第四版”）。
> 第三版：按“拥挤、不够简洁”的反馈做减法（见文末“简洁化”）。
> 第二版：按现有表格《博达-1012进销存》核对结构，保留原布局，整体视觉改为 macOS 系统风格（见文末“macOS 风格要点”）。

**核心布局。** 左侧为可收起的轻材质侧栏（工作台 / 汇总与计划 / 数据与核对三组入口），顶部常驻全局搜索（`/` 键聚焦）与“演示身份/密度/主题”控件，其下一条“逐模块来源日期”横条把销量、FBA、国内、AWD、货件、库龄各自的日期与“沿用旧周期/阻断”状态分开显示。默认进入**国家主表**：SKU 行是主体，七国用分段控件切换（AE 标“部分”、SA 标“简表”），同一张表内用八个视图切换综合总览、月历史、周历史、未来计划/目标、发货计划、批次与在途、库存明细、商品资料。SKU 与品名两列冻结，表头吸顶，宽表在表格自身容器内横向滚动。

**SKU 统一详情是一个完整页面而不是抽屉。** 顶部固定区包含“返回来源（带页码）”、上一个/下一个 SKU、国家切换（全部国家 + 有记录的国家）、同国多 Listing 选择和分区锚点；下面依次是总览、历史销量、未来计划/目标、发货计划、批次/在途、库存明细、资料/来源。每个面板标注数据层级（SKU 聚合层 / 国家层 / Listing 层 / 商品层），避免把共享国内库存与 Listing 数据混算。

**为什么适合进销存。**
- 一份状态，多处入口：计划量、备注、半月计划、批次选择、冲突状态都存在同一个状态对象里；国家页、人员页、搜索、发货计划、详情和总销量 DL:EE 汇总读写同一份数据，改一处其他入口同步。
- 同月比较优先：月历史固定“年份为行 × 1—12 月为列”，所有可用年份默认展开，点月份表头高亮所有年份同月（表头附文字“● 已高亮”）；“截至 10/11”只标在 2026×10 这一格；US/CA/AU/UK 的 2022/2023 单独成行标“仅年总量”。
- 数值语义不混：缺报“未提供”、源表“无字段”、期间“未发生”、源表旧期“空”、原公式“待接入”、真实 0 分开显示；负差异保留负号并标红，同时有“多收/少收”文字。
- 证据随手可查：列头副标题写源列（如 `HT列 · 人工`、`J=HT/I（局部已证）`、`BQ · 前3个完整月×权重`），可编辑的人工计划格有独立底色和图例，只读源值不可编辑。
- 视觉克制：材质只用于侧栏与工具栏，表格、输入、弹层使用实底；系统字体、等宽数字、细边线和轻阴影；状态同时用文字和图形表达；支持深色、紧凑密度与减少动态效果。

**与另一方案最显著的区别。** 不把业务拆成互不相连的模块：国家主表在一张表里用视图切换承载八类工作，SKU 详情是整页工作区（可同时容纳多年月矩阵、全部周与 20 期宽表），并配合“来源列表上一个/下一个”和精确返回（关键词、筛选、页码、排序、横向滚动位置都恢复），把“按国家/人员找商品 → 对比历史与计划 → 核对库存与批次 → 编辑计划”放在一条连续路径上。

## macOS 风格要点（第二版）

| 部位 | 做法 |
| --- | --- |
| 窗口 | 侧栏顶部三色交通灯（装饰，不可点击）；统一标题工具栏显示当前页面标题与副标题；底部 Finder 式状态栏显示逐模块来源日期 |
| 侧栏 | 毛玻璃半透明、13px 文字、强调色图标；选中项为系统蓝底白字；分组标题为 11px 灰色 |

| 表格 | Finder 列表样式：斑马纹行、细分隔线、吸顶表头、表头细竖分隔、聚焦行浅蓝高亮；人工可编辑格为内嵌文本框 |
| 面板 | 系统设置式内嵌分组：10px 圆角、无粗边框，只用 0.5px 发丝线和轻阴影 |

| 颜色 | 系统蓝 #007AFF / 深色 #0A84FF；系统绿、橙、红、紫用于状态；浅色与深色两套语义色 |
| 字体 | 系统字体（SF Pro / 苹方），正文 13px，表格 12px，标题 22px 粗体，数字等宽 |

## 依据现有表格的调整（第二版）

- 演示商品改为虚构的美术用品（丙烯颜料、水彩本、画笔等），更接近实际品类；SKU 仍用 `DEMO-` 前缀，不含任何真实数据。
- 批次名称改为源表写法 `MMDD`，带 `SY` 的为海外仓批次并单独标注。
- SA 月份改为源表实际的 2025 年 1—9 月（无 10—12 月列）。
- 增加 14 张过程记录表的对应入口（数据更新状态、本次问题汇总、在途批次台账、发货历史记录、接收差异批次对账、变体比例核验、公式错误待核对等）。

## 简洁化（第三版）

- **留白与字号**：内容区边距 28/32px，行高 34px（紧凑 27px），单元格左右 12px，页标题 26px，段落间距加大；表头不再加底色和竖分隔线。
- **说明默认收起**：表头里的来源列号（如 `HT列`、`L/H列`）、表格下方说明段落、图例和面板提示默认隐藏；工具栏右上角 ⓘ 一键显示，偏好记在本浏览器。语义必需的标记仍常显：截至日期、已高亮、预计到仓、已过/当前期间、周起止日期、跨年周。
- **少即是多**：“演示数据”标签只保留在侧栏、工具栏副标题和底部状态栏；国家页默认只显示常用列，ASIN/MSKU/等级/箱数通过“更多筛选 → 显示全部列”打开；等级、标签、待核对、零值显示收进“更多筛选”。
- **状态更安静**：状态列改为圆点 + 一个词（多项时 “+n”），完整原因放在悬停提示；同国多 Listing 由蓝色胶囊改为灰色 “×2”。
- **详情页头部**：返回、SKU 与品名、上一个/下一个合成一行；Listing 选择改为下拉；只有分区导航条吸顶。
- **通知**：最多同时显示 2 条（手机 1 条），3 秒后消失。

## 第四版

- **截至日标记**：月表 2026×10 单元格改为数字右上角的橙色小圆点，悬停显示“截至10/11”；去掉年合计旁的“累计”字样；12 个月份列等宽。
- **年份多选**：月历史、SKU 详情、总销量的月表都有“年份”多选（全部 / 近2年 / 单独勾选任意年份），三处共用同一选择；默认“全部”。
- **列配置（参照领星 ERP）**：综合总览、发货计划、库存明细、商品资料和运营人员视图的表格都有“列配置”。弹层左侧按“商品信息 / 库存 / 销量 / 计划与发货 / 状态”分组勾选，可搜索、可整组全选；右侧“已选”列表可拖拽或用箭头排序，最多固定 4 列（固定列横向滚动时停在左侧）；支持内置模版（库存核对、发货决策、销量对比）、保存为我的模版、恢复默认。SKU 列锁定不可取消。配置与模版保存在本浏览器。
- **运营人员视图**：人员改为顶部一排卡片（姓名、Listing 数、SKU 数、各国分布），下方整宽表格；人员 × 国家矩阵改为按钮展开。
- **版本记录**：数据与核对下新增“版本记录”，列出每次生成的进销存版本（基准日、生成时间、生成人、更新范围、待核对数、状态：当前 / 历史 / 已作废 / 演示未确认），可查看详情，任选两个版本对比各国 FBA、在途、最新周销量及变化最大的 Listing。应用一次演示更新会新增一个未确认版本。
