## 5. 无障碍与视觉

- 颜色：为满足小字 4.5:1 对比度，浅色主题强调蓝从 `#007AFF` 调为 `#0064D1`，次级/三级灰调深；深色主题强调蓝分为“填充 `#0A6FD9`”和“文字 `#56AAFF`”两档；状态标签文字逐色求解到 ≥4.6:1。
- 结构：搜索框加 `combobox` 角色；无文字的复选框补可读名称；可滚动但无控件的表格区域可用键盘聚焦；标题层级不跳级；空表头补文字。
- 图表：逐年对比图有图例、端点标注、十字准线提示框、左右方向键逐月查看；下方月销量矩阵即其表格视图。往年灰阶已用 dataviz 校验脚本验证（浅色、深色均通过）。

## 6. 本轮新增的表现方式

| 位置 | 内容 |
| --- | --- |
| 综合总览 · 趋势图列 | 每行一张近 18 个完整月的月销量小图，最近完整月为蓝点；当月未完整不画入，避免“假下跌”；悬停和读屏会给出最新、最高、最低值。默认列在 1440 宽窗口（含侧栏）下完整显示，不需要横向滚动 |
| SKU 详情 · 逐年同月对比图 | 当年蓝线、往年灰线（越早越浅），空心点为未完整月；跟随年份多选 |
| 月历史 · 色阶 | 可选开关；按每条记录自身最大值分 5 档，未完整月不着色 |
| 批次与在途 · 批次清单 | 一行一批：开关、业务归属日、状态、货件、原量、当前值、提醒 |

## 8. 正式开发交接清单

**可直接沿用**
- 样式令牌（`src/styles.css` 顶部，浅色/深色两套，对比度已校验）、表格与冻结列规则、状态显示规则（缺失/无字段/未发生/真实 0 分开）。
- 列目录与列配置交互（`src/app-cols.js`）：字段分组、适用国家判断、固定列、模版结构可直接映射到后端“用户/团队视图配置”。
- 页面结构与验收用例：`tools/verify.cjs` 的 123 项检查可改写为正式版端到端测试。

**需要后端替换**
| 原型做法 | 正式版需要 |
| --- | --- |
| `S.plans / S.half` 内存保存 | 计划、半月计划的保存接口（带版本号，冲突返回 409 与对方版本） |
| `S.transitSel` | 各国在途批次选择的保存与审计 |
| 模拟导入流程 | 文件上传、指纹、预检、差异预览、确认应用（事务性） |
| 版本记录（演示快照） | 每次正式更新生成不可变快照；对比读快照，不重算 |
| 演示身份 | 登录、角色与权限校验（筛选负责人≠权限） |
| 浏览器存储的列配置 | 用户级、团队级视图配置 |

**接口数据建议（与 `src/data.js` 字段一致）**：Product（pid、SKU、品名、装率、等级、变体组）、Listing（lid、国家、ASIN、MSKU、负责人原字段名与值、源行）、月/周/半月/财年目标序列（期间、值或缺失原因码 NF/NP/FU/EMPTY）、批次与行（业务归属日、类型 FBA/SY、申报量、接收、差异口径、当前值）、库存快照（FBA/国内/AWD/库龄，带来源日期）、问题与过程记录（对应 14 张过程表）。
