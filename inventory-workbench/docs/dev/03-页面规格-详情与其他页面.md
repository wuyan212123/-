## 0. 通用约定（所有页面共用，先读）

### 0.1 页面骨架

| 元素 | 结构 | 说明 |
| --- | --- | --- |
| 页头 `.page-h` | `<div class="page-h"><div class="grow"><h1>标题</h1><div class="sub">副标题</div></div>{DEMO_TAG}</div>` | `DEMO_TAG` 恒为空字符串（演示标识统一放在侧栏、工具栏副标题和底部状态栏）。h1 26px/700，窄屏（≤720px 媒体段）19px；sub 13px、`--text-2`、最大 72ch。 |
| 面板 `.panel` | 圆角卡片；内部常见 `.panel-h`（标题栏，min-height 50px，下边线）、`.filters`（筛选条，`padding:12px 16px`，flex-wrap）、`.panel-b`（内容）、表格、`.pager`、`.note` | `.panel-h h2/h3` 13px/600；`.panel-h .hint` 11.5px `--text-2`。 |
| 提示框 `.callout` | `<div class="callout {warn|info|demo}">{图标}<div>文字</div></div>` | warn 用 `warn` 图标，info 用 `info` 图标，demo 用 `flask` 图标。 |
| 说明行 `.note` | `<div class="note">{info 图标} 文字</div>` | 11.5px，`--text-2`。 |
| 空状态 `.empty` | `<div class="empty"><h2>标题</h2><div>正文</div></div>` | 居中，`padding:36px 16px`；h2 15px/600。 |
| 指标卡 `.metric` | `<div class="metric"><div class="k">名称</div><div class="v">值</div><div class="d">说明</div></div>` | k 11.5px；v 24px/600 等宽数字；d 11.5px `--text-3`。放在 `.grid3`（auto-fit, minmax(min(100%,230px),1fr), gap 14px）中。 |
| 键值列表 `.kv` | `<dl class="kv"><dt>…</dt><dd>…</dd>…</dl>` | 两列网格；窄屏变一列。 |
| 汇总条 `.sumstrip` | 一行若干 `<span>…<b>数</b></span>` | 12.5px，`--text-2`，数字加粗。 |

### 0.2 “简洁模式”：说明默认隐藏

CSS 默认隐藏：表头副标题 `.th-sub`、所有 `.note`、`.legend`、`.panel-h .hint`。工具栏右上角 ⓘ（`#infoBtn`，`data-act="info"`）切换 `body.show-info` 后才显示。状态存在 `localStorage` 键 `ivw:showInfo`（读回时只有严格等于 `true` 才算开启；同理 `ivw:collapsed` 只认 `true`，`ivw:theme` 只接受 `system/light/dark`，`ivw:density` 只接受 `comfortable/compact`，坏值回到默认）。切换时 toast：开 `已显示说明与字段来源`，关 `已隐藏说明与字段来源（右上角 ⓘ 可再打开）`。
**还原要求**：本文所有“副标题（sub）”“hint”“note”文案都要渲染进 DOM，只是默认 `display:none`。表头 `.th-flag`（蓝色小字）**不**受此开关影响，始终显示。

### 0.3 值渲染 `V(v, o)`（全站统一）

| 输入 | 输出（文字 / title） |
| --- | --- |
| 数字 | `Intl.NumberFormat('zh-CN')` 取整千分位；`o.dec` 时保留 1 位；`o.signed && v>0` 前加 `+`；负数加类 `neg`。 |
| 数字 0 且“零值显示为空白”开启且未传 `keepZero` | 空 `<span class="zero-hidden" title="真实0（零值隐藏显示，底层仍为0）">` |
| `'NF'` | `无字段`，title `源表无该字段：不是0` |
| `'NP'` | `未提供`（类 `na np`），title `来源缺报/未提供：不是0` |
| `'FU'` | `未发生`，title `期间未到` |
| `'EMPTY'` | `空`，title `源表该期为空，不显示为0` |
| `'ERR'` | `#REF!`（类 `na err`），title `上游错误值` |
| `'PENDING'` | `待接入`，title `原公式结果尚未接入` |
| `null/undefined/''` | `o.nullText`（默认 `—`），title `o.nullTitle`（默认 `未填写/无数据`） |

标签 `tag(cls, txt, icon, title)`：`<span class="tag {cls}">{图标}{文字}</span>`，cls 取 `ok / warn / bad / info / demo / mute / line / layer`。
层级标签 `layerTag(l)`：`sku→SKU聚合层`、`country→国家层`、`listing→Listing层`、`product→商品层`（类 `tag layer`，描边小字 10.5px）。
负责人 `ownerHtml(l)`：有值显示名字；为空显示 `tag('warn','未分配','warn')`，title `源记录负责人为空；不沿用上一行、不从其他国家补人`。

### 0.4 通用表格 `table(id, cols, rows, o)`

* 输出 `<div class="tbl-wrap {o.wrapCls}" id="{id}" style="--fz1w:{o.fz1w||172}px"><table class="t" data-pins="{固定列数}">`。
* 列定义字段：`key`、`label`、`sub`（表头副标题 `.th-sub`）、`flag`（表头蓝色标记 `.th-flag`）、`cls`（`l` 左对齐、`c` 居中、`mono` 等宽、`wrap` 允许换行；默认右对齐数字）、`fz`（冻结列 1/2）、`pin`、`title`（表头悬停说明）、`sort`、`tdCls(row)`、`render(row)`。
* 空表：`<tr><td colspan=列数 class="l"><div class="empty"><h2>{o.emptyTitle||'没有匹配的记录'}</h2><div>{o.emptyText||'调整或清空筛选条件后重试。'}</div></div></td></tr>`。
* 可排序列：表头加 `sortable`、`data-act="sort"`、`tabindex=0`、`aria-sort`；排序指示 `▲`（升）/`▼`（降）。点击循环：未排→升序→降序→取消。表头上按 Enter/空格等同点击。空值按 `-Infinity` 处理（升序排最前）。
* `wrapCls:'auto-h'`：表格不限高（否则 `.tbl-wrap` 有最大高度、内部滚动；窄屏 70vh）。
* 渲染后：若表格可滚动且内部无可聚焦控件，自动加 `tabindex=0 role=region aria-label="{所在面板标题}（可滚动）"`。

分页 `pager(scope,total,page,size,sizes)`：`共 <b>{total}</b> 条` · 弹性空白 · `每页 <select>`（aria-label `每页条数`，id `ps-{scope}`）· 上一页图标按钮（id `pg-{scope}-prev`，aria-label `上一页`，第 1 页禁用）· `第 {page} / {pages} 页` · 下一页图标按钮（id `pg-{scope}-next`，aria-label `下一页`，最后一页禁用）。两个按钮的固定 id 用于翻页后恢复键盘焦点（见 §0.5）。改每页条数时回到第 1 页。页码越界时自动夹到最后一页。
分页状态 `pstate(scope)`：`people/search/total` 用各自页面状态；其他（`plan`、`st-*`、`rec-*`）存在 `S.tp[scope]`，默认 `{page:1,size:25}`，可选 `[25,50,100]`。

分段控件 `seg(items, cur, act)`：`<div class="seg" role="tablist">` 内 `<button role="tab" aria-selected data-act data-v>`；有计数时追加 ` <span class="cnt">{n}</span>`。

SKU 按钮 `skuCell(l, list)`：`<button class="sku-btn" data-act="sku" data-pid data-cc data-lid [data-list] title="打开 {SKU} 统一详情">{SKU}</button>`；同国同 SKU 有多个 Listing 时追加 `<span class="multi" title="同国同 SKU 有 {n} 个 Listing（ASIN/MSKU 各自独立）">×{n}</span>`。

状态单元 `statusCell(l)`：按优先级收集 `同事已改`(bad) / `未保存`(warn) / `待核对`(warn，来自问题或变体零分母/组外/上游错误) / `未分配`(warn)；无则 `正常`(ok)。只显示第一项文字，多于一项追加 ` +{n-1}`；title 为全部原因以 `；` 连接。样式为圆点 + 文字（`.st ok/warn/bad`）。外层包 `<span data-derived="st-{lid}">`（内部内容由 `statusInner(l)` 生成），编辑计划量时只替换这个 span 的内容，不整页重绘。

### 0.5 重绘与焦点

* 所有筛选、切换都会整页重绘 `rerenderKeep()`：保留 `#main` 纵向滚动、每个带 id 的 `.tbl-wrap` 横纵滚动、当前焦点控件（按 id 或 `data-act`+参数匹配），文本框光标放到末尾。
* 焦点回退：重绘后找到的同一控件若已禁用（如翻到最后一页后的“下一页”），改为聚焦它所在的 `.pager` / `.row` / `.detail-head` 内第一个可用按钮；找不到容器或可用按钮时聚焦 `#main`。
* 文本筛选框（`cq/sq/tq/plq`）输入停止 260ms 后才处理，四个框**各自独立计时**（在一个框里输入不会取消另一个框待处理的筛选）；中文输入法拼写中（`isComposing`）不处理，`compositionend` 再处理。
* `plan/note/half/smulti` 每次输入立即处理（不整页重绘，见发货计划联动）。
* 下拉/复选等走 `change` 事件。

### 0.6 弹层通用行为 `modal(html, cls)`

* 结构：`#modal-root` 内 `<div class="modal-back" data-act="modal-bg"><div class="modal {cls}" role="dialog" aria-modal="true">…</div></div>`；`aria-labelledby` 指向 `.modal-h h2`（无 id 时赋 `modal-title`）。
* 打开时记住当前焦点；把焦点放到首个可用按钮/输入。
* 关闭方式：① 标题栏右侧关闭图标按钮（`data-act="close"`，aria-label `关闭`）；② 底部关闭/完成按钮（`data-act="close"`）；③ 点击遮罩本身（点在 `.modal` 内部不关）；④ Esc（同时收起搜索浮层）。关闭后焦点回到打开前的控件（若仍在文档中）。
* Tab 在弹层内循环。
* 结构约定：`.modal-h`（h2 + 状态标签 + 弹性空白 + 关闭按钮）、`.modal-b`（内容，常带 `stack`）、`.modal-f`（按钮行）。

### 0.7 Toast

右上角通知卡：图标 + `进销存工作台` + 小字 `现在` + 消息；3.2 秒消失；同时最多 2 条（窗口 <720px 时 1 条）。warn 类型图标为橙色警告。

参考截图：`docs/screenshots/04-sku-detail.png`、`18-yoy-chart.png`、`20-projection.png`、`w1440-*-detail.png`、`w768-*-detail.png`、`w375-*-detail.png`。

### 1.1 进入方式与初始状态 `openSku(pid, o)`

触发：任意 `data-act="sku"` 按钮（先关闭弹层）、工具栏搜索浮层候选（`popsku`）、验收场景 `goto sku:…`、批次弹层内 SKU 按钮。

| 步骤 | 规则 |
| --- | --- |
| 记录来源 | 当前不在详情页时，`S.nav = [{ page, label: contextLabel(), scroll: #main.scrollTop, tables: 所有 .tbl-wrap[id] 的 [scrollLeft, scrollTop], list }]`。已在详情页内再打开 SKU 时**不**覆盖来源（返回仍回到最初的列表页）。 |
| 默认国家 | `o.country`（按钮的 `data-cc`）；没有时若来自国家主表则用当前国家；该 SKU 在此国有记录→该国，否则→`ALL`（全部国家）。 |
| 默认 Listing | `o.lid`；没有且国家非 ALL → 该国第一条 Listing；国家为 ALL → `null`。 |
| 上一个/下一个序列 `list` | `o.list`（按钮 `data-list`，逗号分隔 pid）→ 来源记录的 list → 全部商品 pid 顺序。 |
| 其他初值 | `wyear:'2026', wfrom:null, wto:null`（周历史控件），`projLid` 未设。 |
| 渲染 | `S.page='detail'`，滚到顶部，焦点移到 `#main`。 |

`contextLabel()`（来源文字，用于工具栏副标题、返回按钮 title、返回 toast）：

| 来源页 | 文案 |
| --- | --- |
| country | `{国家中文名} {代码} · {视图名}`，页码>1 追加 `（第{n}页）` |
| people | `运营人员视图 · {人员|未分配}`，页码>1 追加 `（第{n}页）` |
| search | `搜索结果`＋有关键词时 `“{q}”`，页码>1 追加 `（第{n}页）` |
| total / versions / stock / plan / update / coverage | `总销量` / `版本记录` / `库存汇总` / `发货计划` / `数据更新与异常` / `原表覆盖与验收` |
| 其他 | `上一页` |

侧栏高亮：详情页时高亮来源页（`S.detail.from.page`，缺省 country）。
工具栏：标题 = SKU；副标题 = `SKU 统一详情 · 来自 {来源文字}`（无来源时 `国家主表`）。

### 1.2 页头 `.detail-head`

flex 换行布局，三块：

1. 返回按钮：`<button class="btn" data-act="back" title="返回 {来源文字}">{左箭头图标} 返回</button>`。
2. 标题区（`grow`）：
   * `<h1>{SKU} <span class="h1-name">{品名}</span></h1>`：h1 22px/700 等宽字体；品名 15px/500 `--text-2` 正常字体、左距 8px；窄屏品名换到下一行（`display:block`）。
   * 第二行小字：`{国家数} 个国家 · {Listing 数} 条 Listing · 装率 {装率|缺} · 等级 {等级}`；SKU 有问题时追加 ` · <span class="st warn">待核对 {n}</span>`（问题数 = 该 SKU 所有 Listing 的问题 + 商品级问题）。
3. 序号与翻页（gap 4px）：小字 `{序号} / {总数}`（SKU 不在序列中时为空）；`上一个 SKU` 图标按钮（id `pn-prev`，上箭头，`data-act="pn"`）、`下一个 SKU` 图标按钮（id `pn-next`，下箭头）；到头/到尾时 disabled。aria-label 与 title 都是 `上一个 SKU` / `下一个 SKU`。

**上一个/下一个 `pn`**：切到新 pid；若当前国家非 ALL 且新 SKU 在该国有记录，保持该国并选该国第一条 Listing，否则国家变 ALL、Listing 为空；整页重绘并滚到顶；之后把焦点放回**同一个按钮**（按 id `pn-prev`/`pn-next` 找回；该按钮在新 SKU 下已禁用时聚焦 `#main`），键盘用户可连续按 Enter 翻页。来源记录、周控件状态、推演对象 `projLid` 不清空（`projLid` 不在新 SKU 候选里时自动忽略）。

### 1.3 国家切换与 Listing 选择

`<div class="row" style="margin:14px 0 4px" role="group" aria-label="国家切换">` 内：

* 分段 `.seg`（注意：这里按钮用 `aria-pressed`，不是 tab）：`全部国家`、`US`、`CA`、`AU`、`UK`、`EU`、`AE`、`SA`（固定七国顺序）。`data-act="dcountry"`。
* 禁用规则：该 SKU 在某国没有 Listing → 按钮 `disabled`，title `该SKU在{cc}没有记录`。“全部国家”永远可点。
* 点击：国家=所选；Listing = 该国第一条（ALL 时为空）；保留滚动重绘。
* Listing 下拉：**仅当**国家≠ALL 且该国有 >1 条 Listing 时显示：`<label class="grp small muted">Listing <select id="dlid" aria-label="选择 Listing">`，选项文字 `{MSKU} · {负责人|未分配}`。改选后 Listing 与国家同步。

国家选择的作用域：只影响“历史销量”（逐年对比图对象、月矩阵、周历史）、“未来计划/目标”的半月/财年表，以及推演对象默认值。总览、发货计划表、批次、库存、资料**始终显示该 SKU 全部 Listing**。

### 1.4 分区锚点导航（吸顶）

* `<nav class="anchors" aria-label="详情分区">`，七个按钮 `data-act="anchor" data-id`：`总览`→`sec-ov`、`历史销量`→`sec-hist`、`未来计划/目标`→`sec-fut`、`发货计划`→`sec-plan`、`批次/在途`→`sec-batch`、`库存明细`→`sec-stock`、`资料/来源`→`sec-src`（注意锚点文字无空格，分区标题有空格）。
* 样式：`position: sticky; top:-28px`（窄屏 -20px），左右负外边距铺满主区，下边细线，背景 `--bg` 85% + 毛玻璃；横向可滚动但隐藏滚动条。按钮 12.5px，`--text-2`；当前分区按钮 `.on`：白字 + `--accent` 底。
* 点击：`scrollIntoView({block:'start'})`，`prefers-reduced-motion: reduce` 时瞬移，否则平滑。分区 `.sec` 有 `scroll-margin-top:150px`。
* 当前分区判定：监听 `#main` 滚动；在七个分区中取**最后一个**顶端距视口 <220px 的分区，默认第一个。离开详情页时解除监听。
* 分区之间间距 36px；分区标题 `.sec-title` 18px/700，flex，后接层级标签。

### 1.5 分区一：总览 `#sec-ov`

标题：`总览` + `SKU聚合层`。

指标卡（`.grid3`，4 张）：

| k | v | d |
| --- | --- | --- |
| `国内现货 · 共享池（只计一次）` | 国内现货（亚马逊仓可用） | `亚马逊二部 · 亚马逊仓可用；各国页面只引用` |

| key | 列名 | sub | 渲染 |

## 3. 全局搜索

### 3.1 搜索算法（页面与浮层共用 `searchProducts(q, o)`）

* 归一化 `norm`：转小写并去掉空白、`-`、`_`、`.`、`/`、`·`。空查询返回空。
* 对每个商品的每条 Listing（先按 `o.country`、`o.owner` 过滤；`__none` 只保留负责人为空的 Listing），对字段 `SKU`、`品名`、`ASIN`、`MSKU` 打分：

| 条件 | 分 |
| --- | --- |
| 归一化后完全相等 | SKU 100；其他字段 95 |
| 以查询开头 | 60 |
| 包含查询 | 40 |
| 品名原文包含去首尾空格的查询 | 30 |

* Listing 分 = 各字段最高分；商品分 = 命中 Listing 的最高分；记录命中过的字段集合与命中 Listing 列表。
* 排序：分数降序，同分按 SKU 字母升序。**精确**判定：分数 ≥95。

命中高亮 `markHit(text, q)`：在原文中不区分大小写查找去空格后的 q，找到则只包住该段 `<mark class="mark">`（黄色底 `--hl`、下划线 `--hl-line`）；找不到但归一化后包含，则整段包住；否则原样。

**同步同事新版本 `pullRemote(filter)`**：对每条满足条件的同事版本：本地记录 = 已保存记录（**包括已保存的备注**）+ 同事的数量、版本、修改人、时间，并同时作为新的已保存值；写修改记录 `同步同事 v{版本} 的值 {数量}`（修改人为当前身份）；删除同事版本标记。返回处理条数。

### 11.4 版本冲突弹层 `conflictModal(lids)`

* 内容：
  * 小字段落：`你的修改基于旧版本。为避免后写静默覆盖前写，请逐条选择处理方式。未处理前，你的修改保持“未保存”。`
  * 每条冲突一张 `.metric` 卡：首行 `<b>{国家} · {SKU}</b>` + 等宽小字 `{MSKU} · {planId}`；`.kv`：`你基于的版本` → `v{版本}：{已保存值|空}`；`你的修改` → `<b>{当前值|空}</b>`；`同事的新版本` → `v{远端版本}：<b>{远端值}</b>（{人}，{时间}）`；单选组（name `cr-{lid}`）：`采用同事的值`（默认选中）/ `重新核对后用我的值覆盖`。
  * 复选框 `#cr-ack`：`我已核对同事的新版本（选择“用我的值覆盖”时必须勾选）`。

  * **采用同事的值**：该记录本人的**全部**修改作废（包括备注）——记录 = 已保存记录 + 同事的数量、版本、修改人、时间，并作为新的已保存值；日志 `冲突处理：采用同事 v{版本} 的值 {值}（放弃本人对该记录的修改）`；计入“采用”条数。
  * **用我的值覆盖**：只把本地版本号对齐到同事版本，保留本人修改（仍为未保存）；日志 `冲突处理：核对 v{版本} 后以本人值覆盖`。
  * 两种情况都清除该记录的同事版本标记。
  * 然后关闭弹层并执行正常保存 `commitAll(采用条数)`：覆盖的记录版本再 +1 写入；toast 为 `已保存 {n} 项到本次演示；采用同事的值 {a} 条。`（有同步时再追加 `，同步同事的新版本 {s} 条`；没有采用也没有同步时就是普通保存提示），见 §6.3。
