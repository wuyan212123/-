## 1. 页面结构（自上而下）

整页由 `PAGES.country()` 返回一段 HTML 字符串，注入 `#main`。外壳（侧栏、工具栏、来源条、保存条）不属本页，但工具栏标题受本页影响：

- `#tbTitle` = `国家进销存`
- `#tbSub` = `` `${D.CMAP[S.country].name} ${S.country} · ${viewName(cui(S.country).view)} · 演示数据` ``（如“美国 US · 综合总览 · 演示数据”）
- `viewName`：`{ overview: '综合总览', month: '月历史', week: '周历史', future: '未来计划/目标', plan: '发货计划', batch: '批次与在途', stock: '库存明细', info: '商品资料' }`

### 1.1 结构树（DOM/类名要点）

```
div.page-h
  div.grow
    h1                      `${cfg.name} ${cc} · 国家进销存`         例：美国 US · 国家进销存
    div.sub                 `${listingsOf(cc).length} 条 Listing · 点击 SKU 查看统一详情${cfg.fbaPool ? ' · FBA 共享库存池取 DE' : ''}`
  div.seg.country-tabs[role=tablist][aria-label=国家]
    button[role=tab][aria-selected][data-act=country][data-v=<code>][title="<name> · <TIER_TXT>"]  ×7
       文本 = code；tier≠full 时追加 ` <span class="cov">部分</span>`（ae）或 `简表`（sa）
div.callout.warn[style=margin-bottom:12px]     ← 仅 AE / SA（covMissing 非空）
div.panel
  div.panel-h
    div.seg[role=tablist][aria-label=工作视图]
      button[role=tab][aria-selected][data-act=cview][data-v=<viewId>]  ×8
         文本 = label；viewAvailable=false 时追加 ` <span class="cnt">未设</span>`
  div.filters                                   ← 主筛选行
  div.filters.more                              ← 仅 S.moreF=true
  <视图主体>                                     ← countryView(...) 或 notApplicable(...)
  div.pager                                     ← 仅 7 个列表视图且视图可用
```

### 1.2 页头

| 元素 | 规则 |
|---|---|
| 标题 h1 | `` `${cfg.name} ${cc} · 国家进销存` ``；`.page-h h1` 26px/700，≤ 窄屏 19px |
| 副标题 `.sub` | `` `${N} 条 Listing · 点击 SKU 查看统一详情` ``；EU（`fbaPool: 'DE'`）追加 ` · FBA 共享库存池取 DE`。N 是本国全部 Listing 数，不受筛选影响（演示数据：US 23、CA 17、AU 14、UK 20、EU 18、AE 8、SA 6） |
| 国家分段控件 | `.seg.country-tabs`，顺序 `D.COUNTRIES`：US、CA、AU、UK、EU、AE、SA。按钮 `title` = `` `${x.name} · ${TIER_TXT[x.tier]}` ``，`TIER_TXT = { full: '五国完整结构', ae: 'AE 部分结构', sa: 'SA 简表' }`。AE 按钮文本后跟 `<span class="cov">部分</span>`，SA 跟 `<span class="cov">简表</span>`（`.cov`：9.5px、圆角胶囊、`var(--fill)` 底） |

### 1.3 视图分段控件（8 个视图）

`VIEWS`（顺序固定）：

| id | label | need | viewAvailable 规则 |
|---|---|---|---|
| overview | 综合总览 | — | 恒 true |
| month | 月历史 | — | 恒 true |
| week | 周历史 | weeks | `cfg.weeks` |
| future | 未来计划/目标 | half | `cfg.half` |
| plan | 发货计划 | plan | `cfg.half \|\| cfg.stocking` |
| batch | 批次与在途 | — | 恒 true |
| stock | 库存明细 | — | 恒 true |
| info | 商品资料 | — | 恒 true |

- 不可用视图按钮仍可点击，文本后加 ` <span class="cnt">未设</span>`。结果：US/CA/AU/UK/EU 无“未设”；AE 的“周历史”“未来计划/目标”有“未设”；SA 的“周历史”“未来计划/目标”“发货计划”有“未设”。
- 选中不可用视图时主体渲染 `notApplicable(cc, v)`，且不显示列配置按钮、不显示分页。
- `.panel-h .seg button` 最小高 26px、左右内边距 12px。

`notApplicable` 文案：

```html
<div class="empty" style="border-top:1px solid var(--line)"><h2>${v.label}：不适用</h2><div>${why}。这里不补造同样结构，也不用 0 代替。该国已有的数据可在“综合总览 / 月历史 / 批次与在途 / 库存明细”及 SKU 统一详情中查看。</div></div>
```

`why`：week → `本国原表没有周销量区`；future → `本国原表没有 20 期半月计划与 APR—MAR 财年月目标区`；plan → `本国原表未设补货数量区（发货推演）`。

### 1.6 数据流与分页

```
all  = listingsOf(cc)                        // 本国全部 Listing（源顺序）
rows = filteredListings(cc)                  // 筛选 + 排序（sortRows(rows, c.sort, LISTING_SORT)）
pages = max(1, ceil(rows.length / c.size));  若 c.page > pages → c.page = pages
pageRows = rows.slice((page-1)*size, page*size)
```

- 分页器：仅视图 ∈ {overview, month, week, future, plan, stock, info} 且可用时显示，`pager('country', rows.length, c.page, c.size, [8, 12, 25, 50])`。批次视图另用自己的分页（见 3.6）。
- 分页器 DOM：

```html
<div class="pager"><span>共 <b>${total}</b> 条</span><span class="spacer"></span>
  <label class="row">每页 <select class="sel" data-in="pagesize" data-scope="country" id="ps-country" aria-label="每页条数">8/12/25/50</select></label>
  <button class="btn sm" id="pg-country-prev" data-act="page" data-scope="country" data-p="${page-1}" [disabled 若 page<=1] aria-label="上一页">${icon('left')}</button>
  <span>第 ${page} / ${pages} 页</span>
  <button class="btn sm" id="pg-country-next" data-act="page" data-scope="country" data-p="${page+1}" [disabled 若 page>=pages] aria-label="下一页">${icon('right')}</button></div>
```

- 分页按钮有固定 id：`pg-${scope}-prev` / `pg-${scope}-next`（本页为 `pg-country-prev` / `pg-country-next`），便于翻页重绘后焦点回到同一按钮；目标按钮变为禁用时按 `rerenderKeep` 的回退规则改聚焦同一 `.pager` 内第一个可用按钮（Q1）。
- 月历史 / 周历史 / 未来计划 也按 `pageRows` 分页（每个 Listing 一组）。

### 1.7 排序

- 可排序列表头：`<th class="... sortable" data-act="sort" data-key="${key}" data-scope="country" aria-sort="none|ascending|descending" tabindex="0" role="columnheader">`。当前排序列标题后追加 `<span class="sort-ind" aria-hidden="true">▲</span>`（升序）或 `▼`（降序）。键盘 Enter/空格触发点击。
- 循环：无 → 升序（dir 1）→ 降序（dir −1）→ 无。
- 取值 `LISTING_SORT`：

| key | 取值 |
|---|---|
| cover | `coverSortKey(r)`（见 6.3） |
| sku | `r.sku` |
| fba | `r.fba` |
| transit | `transitOf(r.lid)` |
| avg4 | 数值则 `r.avg4`，否则 `null` |
| plan | `planQty(r.lid)` |
| m9 | `r.monthly[2026]?.[8]` 为数值时取之，否则 `null` |
| owner | `r.owner \|\| ''` |

- `sortRows`：`null/''` 视为 `-Infinity`（升序时排最前）；稳定排序（`slice().sort`）。
- 排序状态存在 `cui(cc).sort`，按国家各自记忆；所有表格视图（overview/plan/stock/info）共享这一个排序。月/周/未来视图虽然不显示可排序表头，但行顺序同样受 `c.sort` 影响（`filteredListings` 始终排序）。

## 3. 各视图规格

通用：除批次视图外，表格 id 统一为 `tbl-${cc}-${后缀}`；`table()` 输出 `<div class="tbl-wrap ${wrapCls}" id="${id}" style="--fz1w:172px"><table class="t" data-pins="${固定列数}"><thead>…</thead><tbody>…</tbody></table></div>`。

- 表头单元格 `th(c)`：`<th class="${c.cls} ${fz?} ${pin pin-N pin-last?} ${sortable…}" … title="${c.title}">${label}${sort-ind}${c.flag ? <span class="th-flag">flag</span>}${c.sub ? <span class="th-sub">sub</span>}</th>`。顺序：标签 → 排序箭头 → th-flag（蓝色 10.5px，始终可见）→ th-sub（灰 10px，仅 show-info）。
- 数据单元格：`<td class="${c.cls} ${fz?} ${pin…} ${c.tdCls(r)}">${c.render(r)}</td>`。
- `cls`：`l` 左对齐、`c` 居中，默认右对齐；`mono` 等宽。
- 空表：`<tr><td colspan="${列数}" class="l"><div class="empty"><h2>${emptyTitle || '没有匹配的记录'}</h2><div>${emptyText || '调整或清空筛选条件后重试。'}</div></div></td></tr>`。
- `.tbl-wrap`：`overflow:auto; max-height:min(68vh, calc(100dvh - 250px)); min-height:100px`；`.auto-h` 取消最大高度。表头 sticky top:0。偶数行 `var(--row-alt)`，悬停行 `var(--row-hover)`，行内有焦点时 `var(--accent-soft)`。
- 冻结列：`fz1`（left:0，宽 `--fz1w` 默认 172px）、`fz2`（left:`--fz1w`，右侧阴影）；`fz1.last` 用于只有一列冻结时。窄屏（≤720px 的媒体查询内）`fz2` 改为 static，阴影移到 fz1。
- 固定列（列配置）：`pin pin-${i}`，最后一个加 `pin-last`（右侧阴影）。`applyPins()` 在 rAF 中按表头单元格实际宽度累加计算每列 `style.left`；窗口 resize、密度切换时重算。≤720px 时只有 `pin-0` 保持 sticky。

### 4.4 固定列规则

- `PIN_MAX = 4`。
- `configuredCols(view, cc, listAttr)`：取 `colCfg(view)`（`S.colcfg[view] || COL_DEFAULTS[view]`）；`pin` = 配置 pin 中同时在 cols 且本国适用的；最终顺序 = `[...pin（按 pin 顺序）, ...其余 cols（按 cols 顺序，过滤本国不适用）]`；每列附 `pin: 序号或 null`、`pinLast: i === pin.length - 1`。
- 表头/单元格类：`pin pin-${i}`，最后一个固定列加 `pin-last`（右侧分隔阴影 `inset -0.5px 0 0 var(--line-strong), 4px 0 6px -4px rgba(0,0,0,.12)`）；`table[data-pins=N]`。
- `th.pin` z-index 4，`td.pin` z-index 2，sticky；`left` 由 `applyPins()` 按前序固定列表头实际宽度累加（遇到 colSpan > 1 的单元格停止）。
- ≤720px：只有 `pin-0` sticky 并带阴影，其余固定列变为普通列。

### 4.5 本地存储与校验

| 键（实际 localStorage 键名） | 内容 | 读取校验 |
|---|---|---|
| `ivw:colcfg` | `{ [view]: { cols: string[], pin: string[] } }`，只读取 `COL_VIEWS` 五个视图 | 每个视图过 `cleanCfg`，不合格的视图丢弃（回落默认） |
| `ivw:tpls` | `[{ name, cols, pin }]` | 非数组 → `[]`；每项需 `name` 为字符串（截取前 40 字），再过 `cleanCfg`，无 cols 的丢弃 |

`cleanCfg(c)`：
1. `c` 为空或 `cols`/`pin` 不是数组 → `null`；
2. `cols` 只保留字符串且属于全量列键 `ALL_COL_KEYS`（`colCatalog(null)` 的全部 key）；为空 → `null`；
3. 不含 `sku` 则插到最前；
4. 返回 `{ cols: 去重(cols), pin: pin 中属于 cols 的前 4 个 }`。

`store` 读写均 try/catch，存储不可用时静默失败。

## 6. 可撑天数（断货风险条）与趋势小图

### 6.1 模型（`src/app-cover.js`，演示估算）

常量：`SAFETY_DAYS = 14`、`PLAN_LEAD = 7`、`OVER_DAYS = 120`、`PROJ_DAYS = 140`。

| 步骤 | 规则 |
|---|---|
| 适用 | `cfg.half` 为 false（AE/SA）→ `{ na: true }` |
| 日均销量 | `avg4 > 0` 时 `avg4 / 7`，否则 0 → `{ none: true }` |
| 到仓批次 `arrivalsOf(l)` | 本国**所选**批次（`isSelected`）中该 Listing 当前值 > 0 的行；`day` = 已到仓（receiving/closed）取 0，否则 `max(0, eta − 基准日)`；`qty` = 当前值；按 day 升序 |
| 模拟 `simCover(fba, daily, arr)` | `t = 0, stock = fba`；对每批：`out = t + stock / daily`；若 `out < a.day`（到仓前卖完）→ 记录第一次断档 `[gapFrom = out, gapTo = a.day]`，`stock = a.qty`；否则 `stock = stock − (a.day − t) × daily + a.qty`；`t = a.day`。结束 `total = t + stock / daily` |
| 补货线 | `line = tdOf(cc) + 14` |
| 断档天数 | `gap = gapFrom 为 null ? 0 : round(gapTo − gapFrom)` |
| 状态 st | `gap > 0` → `bad`；`total < line` → `warn`；`total > 120` → `mute`；否则 `ok` |
| 结果 | `{ daily, arr, fbaDays: fba / daily, total, gap, gapFrom, gapTo, line, st }` |
| 缓存 | 以 `基准日 \| fba \| avg4 \| String(selOf(cc))` 为签名按 lid 缓存；批次选择变化即失效（P2） |

`COVER_ST = { bad: '断档', warn: '需发货', mute: '偏多', ok: '正常' }`；`coverWord(c)`：bad → `` `断档${gap}天` ``，其他取 `COVER_ST`。

### 6.2 单元格绘制 `coverCell(l)`

| 情况 | 输出 |
|---|---|
| 不适用 | `V('NF')`（国家页中该列本就被移除） |
| 无销量 | `<span class="na" title="近4周均销为 0，无法估算可撑天数">无销量</span>` |
| 正常 | 见下 |

几何：`W = 60, H = 12, MAX = 120`，`x(d) = min(d, 120) / 120 × 60`。

```html
<span class="cv" title="${desc}">
  <svg class="cv-bar" width="60" height="12" viewBox="0 0 60 12" role="img" aria-label="${desc}">
    <rect class="cv-fba"  x="0" y="2" width="${max(1, x(fbaDays))}" height="8" rx="2"/>
    [gap > 0] <rect class="cv-gap" x="${x(gapFrom) + 1}" y="2" width="${max(1.5, x(gapTo) − x(gapFrom) − 2)}" height="8"/>
    [total > softFrom + 0.5] <rect class="cv-soft" x="${x(softFrom) + 1}" y="2" width="${max(1, x(total) − x(softFrom) − 1)}" height="8" rx="2"/>
    <line class="cv-line" x1="${x(line)}" x2="${x(line)}" y1="0" y2="12"/>
  </svg>
  <span class="cv-n">${round(total)}</span>
  [st ≠ ok] <span class="cv-w cv-${st}">${coverWord(c)}</span>
</span>
```

- `softFrom` = 有断档时 `gapTo`，否则 `fbaDays`。坐标均 `toFixed(1)`。
- 颜色类：`.cv-fba` 填 `var(--accent)`；`.cv-gap` 填 `var(--bad)`；`.cv-soft` 填 `var(--tint)`；`.cv-line` 描边 `var(--text-2)` 1.2px。`.cv` inline-flex、gap 5、不换行；`.cv-n` 等宽数字、最小宽 2.2em 右对齐；`.cv-w` 11.5px：`.cv-bad` 红色 500 字重、`.cv-warn` 橙色、`.cv-mute` `var(--text-3)`。列单元格 `cv-c` 左右内边距 8px。
- 悬停/无障碍描述 `desc` 模板：

```
可撑约 ${round(total)} 天（FBA ${round(fbaDays)} 天${arr.length ? ` + 在途 ${arr.length} 批` : ''}）；${gap > 0 ? `${M/D(基准日+gapFrom)} 卖完，${M/D(基准日+gapTo)} 才到仓，断档 ${gap} 天` : COVER_ST[st]}${next ? `；下一批 ${next.label} 预计 ${M/D(next.eta)} 到仓` : ''}；补货线 ${line} 天。演示估算，非原公式
```

  `next` = 第一个 `day > 0` 的到仓批次；日期加法按天取整（`dAdd` 对天数 `Math.round`）。

### 6.3 排序键 `coverSortKey(l)`

`na` 或 `none` → `1e9`（排最后）；`bad` → `gapFrom − 1000`（所有断档排在最前，越早卖完越靠前）；其他 → `total`。升序 = 越急越靠前（P1：升序首行含“断档”）。

### 6.4 列头说明

列头 title：`条形：深色 = FBA 可撑天数，红色 = 到仓前断档，浅色 = 在途到仓后可撑；竖线 = 补货线（运输期 + 安全 14 天，示例参数）。演示估算，非原公式`。与样式一致：`.cv-gap` 为纯色 `var(--bad)` 填充。

### 6.5 趋势小图 `sparkCell(l)`

| 项 | 规则 |
|---|---|
| 区间 | `SPARK_N = 18` 个月，截止“最后完整月”= 基准日所在月的上一月（2026-09），即 2025-04 … 2026-09 |
| 取值 | `l.monthly[y][m-1]` 为数值取之，否则 null（`'NF'`、`'NP'`、缺年等） |
| 不足 | 有效点 < 2 → `V('NF', {})`（显示“无字段”） |
| 几何 | `W = 80, H = 24, pad = 3`；`max = max(1, 各有效值)`；`x(i) = 3 + i × 74 / 17`；`y(v) = 21 − v / max × 18` |
| 折线 | 遇 null 断笔（下一个有效点用 `M` 重新起笔），坐标 `toFixed(1)` |
| 端点 | 最后一个有效点画 `<circle r="2.6">` |
| 描述 | `` `近18个月月销量（${起 YYYY-MM} 至 ${止 YYYY-MM}）：最新 ${最新点年月} ${fmt}，最高 ${年月} ${fmt}，最低 ${年月} ${fmt}${有效点 < 18 ? `；${18 − 有效点} 个月无数据` : ''}` `` |
| 输出 | `<svg class="spark" width="80" height="24" viewBox="0 0 80 24" role="img" aria-label="${desc}"><title>${desc}</title><path d="…"/><circle cx cy r="2.6"/></svg>` |
| 样式 | path 无填充、描边 `var(--text-3)` 1.5px、圆角连接；circle 填 `var(--link)`、描边 `var(--panel)` 1.5px；`svg.spark` 80×24、`overflow: visible`；列 `spark-c` 左右内边距 8px |

当月未完整（2026-10）不画入，避免假下跌。SA 只有 2025-04…09 六个点，AE 有 2025-04 起全部点。
