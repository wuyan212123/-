## 1. 原则：一比一还原 = 原样复用

### 1.1 做法

1. **原样复制 `src/styles.css`**，不重写、不改名、不拆成 CSS Modules / Tailwind / CSS-in-JS。整份 586 行是唯一的样式来源；所有组件都只靠类名 + 属性选择器（`aria-*`、`[data-theme]`）生效。
2. **原样复用 DOM 结构与类名**。本文第 4、6 节给出的 HTML 片段都是从生成函数推导出的真实结构，新工程（无论用 React / Vue / 原生）渲染出的 DOM 必须与之等价：同样的元素层级、同样的类名、同样的 `role / aria-* / data-*` 属性。很多样式依赖层级选择器（如 `.panel-h .seg button`、`.t tbody tr:nth-child(even) td`、`.app.collapsed .nav-label`、`.pop-item:hover .tag`），换层级就会失效。
3. **保留外壳 `shell.html` 的 DOM**（第 4.3 节原文），包括 `#app`、`#sidebar`、`.overlay-scrim`、`.main-col`、`header.toolbar`、`main#main.main`、`footer#srcbar.srcbar`，以及 `#app` 之外的三个挂载点 `#savebar`、`#modal-root`、`#toast`。
4. **保留 `index.html` 包装层追加的 4 条规则**（由 `tools/build.py` 写入 `<style>` 开头，位于 styles.css 之前）：
   ```css
   :root{padding-top:env(safe-area-inset-top,0px);padding-bottom:env(safe-area-inset-bottom,0px)}
   body{margin:0}
   [hidden]{display:none!important}
   ```
   以及 `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`、`<title>进销存协作工作台</title>`、`<html lang="zh-CN">`、`<meta charset="utf-8">`。
   注意 styles.css 本身**没有** `body{margin:0}`，缺了这条页面会出现 8px 白边并产生滚动条。
5. **保留图标函数 `icon()` 的输出格式**（viewBox、stroke-width 1.7、round 端点），见第 7 节。
6. **保留 JS 在运行时写入的内联样式 / 变量**：`--fz1w`（表格冻结首列宽）、`--th1`（二级表头吸顶偏移）、固定列每个单元格的 `style.left`、图表 SVG 的 `width/height`、时间线条的 `left/width`、库龄条的 `flex`。它们不在 CSS 里，但影响外观。

### 1.2 不能改的地方（改了就不是一比一）

| 项 | 要求 |
|---|---|
| 字体栈 | `--font` / `--mono` 原样（见 2.3），不要引入 Web 字体 |
| 基准字号 | `body` 13px / line-height 1.5 / letter-spacing -0.003em |
| 盒模型 | `* { box-sizing: border-box; }` |
| 表单继承 | `button, input, select, textarea { font: inherit; color: inherit; letter-spacing: inherit; }` |
| SVG 默认 | `svg { width:16px; height:16px; flex:none; vertical-align:-3px; }`——所有图标尺寸都以此为基准再覆盖 |
| 表格数字 | `.num, td, .tab-nums { font-variant-numeric: tabular-nums; }` |
| 发丝线 | 分隔线一律 `0.5px solid var(--line)` 或 `var(--line-strong)`，不要改成 1px |
| 焦点 | 统一 `box-shadow: 0 0 0 3px var(--focus)`，不用 outline |
| 主题切换方式 | 跟随系统用 `@media (prefers-color-scheme: dark)` + `:root:not([data-theme="light"])`；手动用 `<html data-theme="light|dark">`；“跟随系统”时 **移除** `data-theme` 属性（app-core.js） |
| 密度切换方式 | 在 `<body>` 上切换 `density-compact` 类（app-core.js） |

## 2. 设计令牌（CSS 变量）

定义位置：浅色 `:root`（styles.css 开头）；深色有**两处完全相同**的定义：
- `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }`
- `:root[data-theme="dark"] { … }`

两处深色块都额外声明 `color-scheme: dark;`。深色块**没有重定义**的变量（`--chev`、`--font`、`--mono`、`--r-page`、`--r-ctl`、`--row-h`、`--cell-px`、`--side-w`）沿用浅色值。

### 2.5 主题

- 状态 `S.theme ∈ system | light | dark`，循环顺序 `system → light → dark → system`（app-main.js），保存在 `ivw:theme`。
- `system`：`<html>` 无 `data-theme` 属性，跟随 `prefers-color-scheme`。
- `light`：`<html data-theme="light">`，即使系统为深色也用浅色（因为深色媒体查询块限定 `:root:not([data-theme="light"])`）。
- `dark`：`<html data-theme="dark">`。
- 主题按钮图标：`system → auto`、`light → sun`、`dark → moon`；title 分别为“主题：跟随系统（点击切换）”“主题：浅色（点击切换）”“主题：深色（点击切换）”。
- 图表颜色不是 CSS 变量而是 JS 写死（见 6.21），切换主题时调用 `drawChartsThemed()` 重绘。

## 3. 排版、间距、圆角、阴影、毛玻璃、层级、动效、焦点

### 3.1 全局基准

```css
html, body { height: 100%; }
body { background: var(--bg); color: var(--text); font-family: var(--font); font-size: 13px; line-height: 1.5; letter-spacing: -0.003em; -webkit-font-smoothing: antialiased; -moz-osx-font-smoothing: grayscale; overflow: hidden; }
* { box-sizing: border-box; }
button, input, select, textarea { font: inherit; color: inherit; letter-spacing: inherit; }
svg { width: 16px; height: 16px; flex: none; vertical-align: -3px; }
:focus { outline: none; }
:focus-visible { outline: none; box-shadow: 0 0 0 3px var(--focus); border-radius: 5px; }
.num, td, .tab-nums { font-variant-numeric: tabular-nums; }
.sr { position: absolute; width: 1px; height: 1px; overflow: hidden; clip: rect(0 0 0 0); white-space: nowrap; }
```

滚动条（WebKit）：宽高 11px；轨道透明；滑块 `background: var(--fill-2); border-radius: 8px; border: 3px solid transparent; background-clip: content-box;`，hover 时 `background-color: var(--text-3)`；角落透明。`.seg`、`.srcbar`、`.anchors` 用 `scrollbar-width: none` + `::-webkit-scrollbar { display:none }` 隐藏滚动条。

## 8. 简洁模式 / 显示说明（`body.show-info`）与演示数据标识

### 8.1 机制

- 默认是**简洁模式**：`<body>` 不带 `show-info`。偏好 `S.showInfo` 存于 `localStorage` 键 `ivw:showInfo`，默认 `false`。
- 工具栏 `#infoBtn`（图标 `info`）切换：
  - 关闭时：`aria-pressed="false"`，title / aria-label = “显示说明与字段来源”。
  - 开启时：`aria-pressed="true"`（按钮呈 `--accent-soft` 底 + `--link` 图标），title / aria-label = “隐藏说明与字段来源”。
  - 切换后 toast：开启“已显示说明与字段来源”，关闭“已隐藏说明与字段来源（右上角 ⓘ 可再打开）”；随后调用 `afterRender()` 重算二级表头偏移与固定列（表头高度会变）。

### 8.2 受影响的元素

| 选择器 | 简洁模式（默认） | `body.show-info` |
|---|---|---|
| `.t th .th-sub`（表头下方的字段来源，如“源值 · 原公式待接入”“BT:CI · 原值回查”） | `display: none` | `display: block` |
| `.note`（面板内的说明段落，`{icon info} …`） | `display: none` | `display: block` |
| `.legend`（图例行，含 `.filters.legend`） | `display: none` | `display: flex` |
| `.panel-h .hint`（面板标题旁的灰色提示） | `display: none` | `display: inline` |
| `.note-inline`（单元格内的行内说明） | `display: none` | `display: inline` |

**不受影响、始终显示**：`.th-flag`（表头状态旗标）、`.callout`（提示块）、`.tag`、`sup.cut` 的橙点及其 `title` 悬停说明、`.yoy-legend / .tl-legend / .ag-legend`（图表自带图例，类名不是 `.legend`）、`.empty` 中的说明文字。
