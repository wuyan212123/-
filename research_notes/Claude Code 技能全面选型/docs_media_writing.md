## Q1. Are there better or complementary PPT and video skills than the installed ones? Which installed ones overlap and should be trimmed?

### Takeaway
The installed set already contains the community leaders: ppt-master (editable .pptx, about 76.6k stars), frontend-slides and guizang-ppt (HTML decks, about 32k and 30k stars), HyperFrames (about 84k stars) and Remotion. Three are worth adding as complements: GordenPPTSkill (fills Chinese .pptx templates), huashu-design (Chinese HTML prototypes and decks, MIT) and, optionally, MiniMax pptx-generator or anthropics/pptx as a lightweight python-pptx/PptxGenJS fallback. For video, digitalsamba's ffmpeg, moviepy, remotion and playwright-recording skills mostly duplicate HyperFrames media plus remotion-dev/skills. Of those, ffmpeg (generic transcoding) is the one to keep. Among HTML decks there are too many overlapping options: frontend-slides, guizang-ppt, HyperFrames `slideshow`, the `design` skill's slides and design-system slides all claim "make a presentation". Keep one or two.

### Inferences
- **Trim candidates.** Run either `video-remotion` (digitalsamba) or the remotion-dev `remotion-*` set, not both; the official remotion-dev set is fresher and more granular. Run `video-moviepy` only if the user really composes video in Python. `video-playwright-recording` overlaps with HyperFrames capture and is worth keeping only for raw browser recording. Among HTML decks, keep frontend-slides **or** huashu-design as the general one, plus guizang-ppt for its signature styles. Its AGPL-3.0 license matters only if the generated runtime code is distributed or served as part of a product. HyperFrames `slideshow` and the `design` skill's slide mode are a third and fourth deck path that will compete for triggering.
- For editable Chinese corporate decks, ppt-master plus GordenPPTSkill (template fill) covers more than adding further HTML-deck skills.
- anthropics `pptx`/`docx`/`xlsx`/`pdf` are now Apache-2.0, so the old licensing reason to prefer MiniMax's MIT office skills no longer applies. Keep the anthropics set as the baseline.

### Gaps
- skills.sh install counts and remotion.dev license thresholds could not be fetched (DNS blocked in the sandbox).
- dashi-ppt's `GXN_TOKEN` purpose and HyperFrames' exact paid-credit prices were not verified.
- No independent quality benchmarks comparing ppt-master, MiniMax pptx-generator and anthropics pptx were found.
