## 0. 一页看懂

1. **选品地图是什么**：按 MEEDEN 2027 产品规划导图的框架，把市场上每个大类、每个小类下的**全部细分形态**列出来；逐一标出 MEEDEN 美国站覆盖到哪一级（L1/L2/L3）；空白处用细分市场指标、三道闸和机会评分筛出开品机会。
2. **为什么这样做**：一个一个猜方向容易漏，也容易重复开发已有产品（前几轮就把 MEEDEN 已在卖的油画棒套装、绷框画布、水彩软头笔误判成了新机会）。先画全地图，再在空白处找机会，是系统性的。
3. **V2 比 V1 多了什么**：工具导出数据（A 级来源）替代搜索收录数据；看整个细分市场而不是一个头部单品；按 L1/L2/L3 拆开看覆盖；三道闸 + 机会评分；每个数据点标来源、日期、可信度。
4. **数据只在一处维护**：`selection_map/data/product_map.json`。
   ```bash
   python3 selection_map/ingest.py   # 导入 selection_map/imports/ 下的工具导出，算指标、闸门、评分
   python3 selection_map/build.py    # 生成 Excel 选品地图和思维导图
   python3 selection_map/tests/test_ingest.py   # 改了脚本后必须跑通
   ```
   团队日常记录用网页版 **MEEDEN 产品地图**（https://claude.ai/artifact/CUpXen3UurqdVRNi6ejMbi ）：在网页里改状态、ASIN、结论、备注，再用导出 JSON + `sync_app_export.py` 合并回仓库。两边怎么分工见第 6.1 节。
5. **进度**：耗材已完成 V1 结构（119 个形态，已迁移到 V2 结构，等待工具导出数据重跑）；艺术家具&收纳已按降级模式完成第 1–5 步（60 个形态，2026-11-03）；快消工具、礼品&套装、画架、DIY、儿童 5 个大类待扫描。
6. **下一步**：产品部按 Excel「待导出清单」导出耗材和艺术家具&收纳数据 → V2 试点 → 再扫描快消工具（见第 10 节扫描队列）。

## 1. 背景：MEEDEN 产品框架

来源：公司《MEEDEN 2027 产品规划》思维导图（产品部 2026 年 8 月输出，数据口径 2025.8–2026.7）。

### 1.1 品牌定位与分级

- 定位：为艺术创作者提供更高质价比的、构建或升级艺术创作空间的全球化解决方案。
- 三大场景：Life 家庭/生活、Learning 学习/教育、Workplace 工作/创作。
- 三个级别：**L1 Beginner（入门）/ L2 Advanced（进阶）/ L3 Professional（专业）**。导图里每个小类都按 L1/L2/L3 列了现有 SKU 和空位，空位标为「规划中」或「？」。
- 渠道：亚马逊为主（亚马逊 + 独立站营收占比 90% 以上），本手册只看**亚马逊美国站**。

### 1.2 大类与公司策略

| 大类 | 现状（SPU / 营收占比） | 导图策略 | 中长期营收目标 |
| --- | --- | --- | --- |
| 画架 | 50 SPU → 规划 57；营收约 32% | 防守、内查、老品优化 | 降到 15% |
| 艺术家具&收纳 | 39 SPU → 规划 52；营收约 20% | 全面进攻 | 升到 25% |
| 耗材（颜料/笔/油画棒/纸/框板布/胶带） | 115 SPU → 规划 149；营收约 28% | 局部进攻，英雄品线 | 30% |
| 快消工具（画笔/调色盘/小工具） | 67 SPU → 规划 76；营收约 13% | 试探性进攻、不打低端、拿来主义 | 升到 20% |
| 礼品&套装 | 8 SPU → 规划 15；营收约 4% | 试探性进攻，节日节点 | 升到 10% |
| DIY 产品 / 儿童产品 | 无 | 待 2028 年规划 | — |

公司整体：279 SPU → 规划 349（+70）；年销售额约 $2,903 万；利润率 17%；客单价约 $35.5。

**执行要求**：选品地图的分类结构必须挂在这个框架上（大类 → 组 → 小类），不自创大类。市场上有、但导图里没有的形态，挂到最接近的小类下，`framework_ref` 写「XX·新小类」或「XX·新形态」。

## 2. 开品思路总纲：选品地图法

```
市场全部形态（类目树 + 新品榜 + 社媒）
        │  对照
        ▼
MEEDEN 美国站已有什么（逐个形态搜索核对，记 ASIN 证据）
        │  差集
        ▼
空白 / 部分覆盖的形态
        │  三道闸：需求（≥ 2 个单品月销 ≥ 1500 或 ≥ $4 万）/ 健康 / 硬伤
        ▼
机会评分（MOS，满分 100）→ 机会清单（A 档立项评审 / B 档观察）
        │  深挖：竞争、差评、利润、合规、组套
        ▼
立项 → 上市 → 3 个月复盘 → 结论回填地图
```

核心原则：

1. **先全后精**：每个大类先把形态列全，再判断机会。漏列比误判更难发现。
2. **拆到能判断是否重复的粒度**：同一小类下，只要规格维度不同就可能是不同的机会。例：「水粉」要拆成管装 / 果冻杯 / 丙烯水粉 / 儿童瓶装；「马克笔」要拆成丙烯 / 酒精 / 水性双头 / 水彩软头 / 油性油漆笔 / 布料 / 金属色。
3. **每个判断都要有证据**：MEEDEN 已有 → 记 ASIN；市场销量 → 记对标单品和数字来源；查不到 → 标「待查」，**绝不编造数字**。
4. **空白 ≠ 机会**：空白位还要过门槛和风险。耗材 60 个空白形态里，只有 10 个过门槛。
5. **地图是长期资产**：每季度复扫一次，状态和销量会变；立项和复盘的结论也回填到地图里。

## 3. 开品标准

### 3.1 硬门槛：三道闸（V2）

「单品达标」的定义不变：月销量 ≥ 1500 单，或月销售额 ≥ $40,000。V2 在此基础上看整个细分市场：

| 闸 | 条件（`meta.thresholds`） | 不通过时 |
| --- | --- | --- |
| G1 需求 | 核心词搜索结果 Top 50 中，至少 2 个单品达标（`g1_min_pass`） | 头部月销 ≥ 500 或有上升信号 → 观察池；否则淘汰 |
| G2 健康 | 第一品牌份额 ≤ 60%（`g2_cr1_max`），且同比不低于 −20%（`g2_yoy_min`） | 观察池（注明「市场集中或萎缩」） |
| G3 硬伤 | 不是危险品（易燃液体、气雾剂） | 淘汰 |

三道闸都过的，按**地图级机会评分（MOS，满分 100）**分档：≥ 70 → A 档立项评审；55–69 → B 档观察池；< 55 → 暂不做。评分维度和计分规则见 V2 方案第 3.9 节，由 `scoring.py` 自动计算。

- 低客单品类（颜料、笔、纸、胶带、笔刷、调色盘，$6–30）基本只能靠 1500 单达标。
- 高客单品类（画架、家具、画车、画柜，$80–300）基本靠 $4 万达标：$100 的产品每月约 400 单即可。**扫描家具和画架时，一定要记售价**，否则门槛判断不准。
- 阈值存在 `product_map.json` 的 `meta.thresholds`；Excel「产品全景图」第 2 行黄色单元格可以临时改来做假设分析，但评分和建议结论以 JSON 里的阈值为准。
- V1 的「1 个头部单品达标」口径保留为 Excel 里的参考列「V1 单品门槛」，便于对比。

### 3.2 软门槛（立项阶段用，地图阶段只记录风险）

- 净利率不低于公司均值 17%；标杆单品参照「BS 前 50、净利 ≥ 13%、有专利」。
- 不卷低价：以差异化和组套取胜。
- 品质：可做到 Review ≥ 4.3、年客诉率 < 5%。
- 开发方式优先级：微创新 > 贴牌 > 全面创新；大件优先能 KD 化。
- 供应链：爆款能分 2–3 家工厂下单。
- 合规：铅笔、颜料、马克笔、儿童产品先过合规（ASTM D-4236、CPSIA、Prop 65）；**易燃液体（油画溶剂、酒精墨水）和气雾剂（定画液、喷雾光油）直接记为高风险**，一般淘汰。

### 3.3 不重复开品的判定

| 情况 | 判定 | 地图里怎么标 |
| --- | --- | --- |
| 同小类 + 同级别 + 核心功能和规格相同（只改颜色/尺寸微调） | 重复 | 状态「已有」，结论「老品升级」 |
| MEEDEN 已有，但市场头部明显更好、有可解决的差评 | 老品升级 | 状态「已有」，结论「老品升级」，备注写对标对象 |
| MEEDEN 只覆盖该形态的一部分（如只有 12 色肤色粉彩铅） | 部分覆盖 | 状态「部分覆盖」 |
| 导图里已排期（如 PNS-3027 26Q3 可售） | 按导图推进 | 状态「规划中」，结论「按导图推进」或并入机会 |
| 导图空位 / 市场有我们没有 | 补位 / 新小类 / 新形态 | 状态「空白」，按门槛判结论 |

## 4. 地图结构与命名规范

### 4.1 层级

| 层级 | 字段 | 说明 | 例 |
| --- | --- | --- | --- |
| 大类 | `category` | 与导图一致的 6 个大类之一 | 耗材 |
| 组 | `group` | 大类下的第一层分组 | 颜料、笔类、本册纸张 |
| 小类 | `subcategory` | 组下的小类；组下不再细分时留空 | 丙烯、马克笔 |
| 形态 | `form` | 地图的最小单位，一行一个 | 酒精马克笔、果冻杯水粉 |

### 4.2 形态拆分规则

- 拆分依据（按优先顺序）：材质/介质 → 形态（管/瓶/杯/棒/笔/纸本/卷）→ 功能（可擦、水溶、夜光、防水）→ 使用场景（儿童、教室、户外、展示）→ 级别（学生级/艺术家级）。
- 只差颜色数量或尺寸的，**不拆**，写进 `spec`（规格维度）。
- 一个形态既属于 MEEDEN 某个已有 SKU 又不完全一样时，标「部分覆盖」并在 `evidence_other` 说明覆盖了哪部分。
- 跨大类的产品按导图归属：马克笔收纳盒归「艺术家具&收纳」，调色盘归「快消工具」，礼盒套装归「礼品&套装」。扫描时发现属于其他大类的 MEEDEN 产品，记到 `extra_existing`，扫描那个大类时直接标「已有」。

### 4.3 编号

- 每个形态一个永久编号，前缀按大类：耗材 `C`、画架 `E`、艺术家具&收纳 `F`、快消工具 `T`、礼品&套装 `G`、DIY `D`、儿童 `K`；后接三位流水号（`F001`）。
- 编号一旦分配不改、不复用。形态被合并或删除时，保留记录并在 `note` 写「已并入 F0xx」。

### 4.4 命名

- `form` 用中文，产品部能直接看懂的叫法，10 字左右；必要时括号补充（如「水性双头马克笔（软头+细头）」）。
- `keyword_en` 写 1–3 个亚马逊美国站买家会搜的英文核心词，用 ` / ` 分隔。它同时是核对 MEEDEN 状态和查销量时的查询词。

## 5. 数据模型：`selection_map/data/product_map.json`

### 5.1 顶层

| 键 | 说明 |
| --- | --- |
| `meta` | 版本、更新日期、门槛、状态和结论的可选值、大类顺序 |
| `records` | 形态记录数组（地图主体） |
| `skeleton` | 待扫描大类的导图骨架（小类、导图现状、导图空位、待纳入的市场形态） |
| `extra_existing` | 扫描时顺带发现、属于其他大类的 MEEDEN 已有产品 |
| `trends` | 新增与上升信号 |

### 5.2 `records` 字段

| 字段 | 必填 | 取值 / 格式 | 说明 |
| --- | --- | --- | --- |
| `id` | 是 | `C001` | 永久编号，见 4.3 |
| `category` | 是 | `meta.category_order` 之一 | 大类 |
| `group` | 是 | 文本 | 组 |
| `subcategory` | 否 | 文本或 `""` | 小类 |
| `form` | 是 | 文本 | 细分形态 |
| `spec` | 是 | 文本 | 规格维度：容量、色数、尺寸、件数等 |
| `keyword_en` | 是 | 文本 | 英文核心词 |
| `framework_ref` | 是 | 文本 | 对应导图的哪一格，如「丙烯 L1」「画柜 L3（规划中）」「笔类·新小类」；导图有内部编码就写上 |
| `meeden_status` | 是 | 已有 / 部分覆盖 / 规划中 / 空白 / 未核对 | 见第 6 节第 2 步 |
| `evidence_asin` | 已有时必填 | 10 位 ASIN | MEEDEN 在售的代表 ASIN |
| `evidence_other` | 否 | 文本 | 其他 ASIN 和说明，如「B0F8B1TTLR 48色；Walmart 也在售」 |
| `benchmark` | 空白/部分覆盖时必填 | 文本 | 对标头部单品：品牌 + 规格 |
| `monthly_units` | 否 | 整数或 `null` | 头部单品月购买量下限；「6K+」记 6000；查不到记 `null` |
| `price_usd` | 否 | 数字或 `null` | 对标单品参考售价（美元） |
| `trend_signal` | 否 | 文本 | 新增 / 上升信号，如「New Releases 榜首类型」 |
| `risk` | 否 | 文本 | 合规、易燃、品牌壁垒、数据存疑等 |
| `conclusion` | 是 | 立项评审 / 观察池 / 淘汰 / 老品升级 / 按导图推进 / 待查 / 待人工复核 | 见第 7 节决策表 |
| `note` | 否 | 文本 | 补充说明和下一步 |
| `checked_on` | 是 | `YYYY-MM-DD` | 最近一次核对日期 |
| `priority` | 机会项必填 | `A1…`（立项评审）/ `B1…`（观察、待复核） | 进入机会清单的排序 |
| `synergy` | 机会项必填 | 文本 | 与 MEEDEN 现有产品的组套协同 |
| `opp_risk` | 机会项必填 | 文本 | 风险 / 难点 |
| `next_step` | 机会项必填 | 文本 | 下一步动作 |

## 6. 执行流程 V2（每个大类 10 步）

### 两种数据模式

| 模式 | 条件 | 做法 |
| --- | --- | --- |
| **标准模式（V2）** | 产品部已按 Excel「待导出清单」导出工具数据 | 按下面 10 步执行，指标全部由 `ingest.py` 计算，可信度「高」 |
| **降级模式（V1 方法）** | 还没有工具导出 | 第 1–5 步照做；第 6 步改用网页搜索记录头部单品（V1 方法：`monthly_units / price_usd / benchmark`），`data_source` 写「C:…」，`confidence` 写「中」或「低」。这些形态的建议结论会是「待数据（V1 单品达标 / 接近 / 偏低）」，并自动出现在「待导出清单」里 |

两种模式下都**不允许编造或推算数字**。

### 第 1 步：读导图骨架和种子形态

- 读 `product_map.json` → `skeleton` 里该大类的小类、导图现状、导图空位、`forms_to_check`，以及本手册第 10 节的起步清单。

### 第 3 步：关键词挖掘与归类

- 完成标准：每个小类覆盖率 ≥ 95%。

### 第 4 步：竞品产品线对照

## 9. 已知坑和教训（耗材扫描中踩过的）

1. **把 MEEDEN 已有产品误判为空白**：彩色水彩软头笔（PNB-3017，24/36 色）、一站式油画棒套装（77/102 件）、绷框画布和画布板都曾被误列为新方向。教训：形态要拆细，每个形态至少两组关键词搜。
2. **标题误导**：荧光丙烯标题写「Glow in Dark」，实为 UV 荧光，不是夜光。
3. **用途不同的同名产品**：Sharpie 洗衣标记笔月购买 8K+，属于标记用途，不能算作「布料绘画马克笔」的市场。
4. **销量标签归属不清**：搜索页里「4K+ bought」等标签可能挂在相邻产品上（金属彩铅、油性油漆笔都遇到过），不能直接用。
5. **页面过旧**：部分搜索收录的亚马逊页面是一年以前的快照（如夜光颜料的 5K+），立项前必须复核。
6. **导图内部编码在美国站搜不到**：如 HBM 画框 23 款、HBM 画板 11 款，美国站搜不到 MEEDEN 画框/画板，需产品部确认是否在美国站销售；在确认前标「空白」并写明。
7. **网络限制**：部分执行环境打不开 amazon.com 等电商页面，只能用网页搜索收录的结果。此时所有销量都视为「下限、待复核」，交付说明里要写明。
