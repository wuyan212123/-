# 05 · 复盘报告规格（v7）

原型参照：`prototype/sp-workbench.html` 中 `// ---------- 复盘报告 ----------` 一节（`repCtx()`、`repBuild()`、`sec*()`、`repDoc()`、`repToc()`、`reportMd()`、`vReports()`）。

## 1. 定位与写法

报告用于保存并沟通本轮判断。旧版是 Markdown 文字稿，维度少、全是文字；v7 改为“结论先行”的报告文档，把复盘分析的各维度带进报告。写法依据：

| 依据 | 落到报告里的做法 |
| --- | --- |
| 金字塔原理 / SCQA | 第 1 节一句话回答“好不好、为什么、下周先做什么”；**每节标题是一句结论**，不是“整体表现”这类主题名 |
| 联想复盘四步法、AAR（After Action Review） | 回顾目标 → 评估结果 → 分析原因 → 总结规律；章节按 结果 / 原因 / 行动 / 沉淀 分组 |
| 亚马逊 WBR（Weekly Business Review） | 本期放进近 12 周里看；连续 2 周同向才算趋势；只解释显著变化；区分可控动作与结果 |
| PPC 代理商周报实践 | 先回看上期动作是否见效（闭环），再给下周动作（优先级、预计影响、负责人、复查日）；金额只用于排优先级 |
| SP 7 天归因 | 封面标出“最近 n 天归因未补全”，附录说明影响 |

● 默认开启，○ 默认关闭。用户可在“报告结构”中按类型单独开关（键 = 类型 + 章节 id）。章节序号只计开启的章节，两位数显示（01、02…）。

类型说明（生成栏中显示）：

- 周报分析：每周例行：结果、上期动作、原因、下周计划。
- 周期对比：大促、调价前后等两个时段的对比，重点看变化归因。
- 关键词复盘：关键词专项：变动、收割、否定与结构。

入口：周期优化 / 关键词页“生成复盘”→ 周报分析（详情打开时为关键词复盘）；复盘分析“生成周期对比报告”→ 周期对比。

```text

┌──────────────┬──────────────────────────────────────────────┐
│ 报告（历史）   │ 生成栏：类型分段 + 类型说明 │ 内置规则 / AI │ 生成 │
│ - 本期 · 草稿  │ （AI 未验证时的提示横幅）                        │
│ - W42 广告周报 │ 元信息栏：范围跟随顶部 │ 复制正文 │ 导出 Markdown │ 确认报告 │ 保存到历史 │
│ …             ├──────────────────────────────────────────────┤
│ 报告结构（目录）│ 报告文档（最大宽度 920px，居中）                  │
│  结果 / 原因 / │  封面 → 01 本期结论 → 02 … → 12 附录             │
│  行动 / 沉淀   │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- 左栏 252px（≤ 1279px 为 216px）。目录吸顶（`position: sticky`），历史在上方。
- ≤ 1100px：单栏；目录隐藏；历史变成横向滚动的卡片条（每张 210px）。
- 历史报告（只读快照）：右侧显示封面（项目 · 类型、标题、A / B、来源、已确认 · 保存时间）和锁定说明“历史报告按保存时的数据与范围固定，不随顶部范围变化”；元信息栏只有复制与导出。
- 生成中：文档区显示“正在按内置规则生成报告…”与骨架屏。

### 3.1 报告结构（目录）

- 顶部说明：“结论先行，按‘目标 → 结果 → 原因 → 行动 → 沉淀’组织；勾选决定报告与导出包含哪些章节。”
- 四个分组标题：结果（回顾目标 · 评估结果）、原因（分析原因）、行动（下期怎么做）、沉淀（总结规律）。
- 每项：勾选框（本期结论禁用）、序号（关闭时为“—”）、章节名、状态点（需处理红 / 需关注琥珀 / 正常绿 / 参考灰）。点击章节名平滑滚动到该节（尊重“减少动态效果”设置）；关闭的章节不可点。

### 3.2 封面

- 首行：项目名 · 类型名。
- 标题：周报分析 `W{A 结束日 ISO 周} 广告周报`；关键词复盘 `W{A 结束日 ISO 周} 关键词复盘`（与周期优化页标题的周号一致）；周期对比 `{A 区间} 对比 {B 区间}`。
- 标签行：A 起止、B 起止（无 B 时省略）、来源、缺日（如“缺 B 10/12”，琥珀）、“最近 n 天归因未补全”（琥珀，悬停说明，n = 规则 `lag`）、“规则生成 / AI 生成 · 生成时间”、状态“草稿 / 已确认”（已确认为绿）。

### 3.3 章节结构

每节自上而下：

1. 眉行：序号（强调色）· 章节名 · 右侧状态点 + 状态文字。
2. **结论标题**（h2）：一句话结论，关键数字可用红色 `<em>` 或绿色 `<em class="up">` 强调。
3. 正文：图表 / 表格 / 卡片 + 要点列表（每条带状态图标）+ 跳转链接。
4. 运营补充：默认是“+ 补充说明”按钮；点开为文本框（经验沉淀一节默认展开，标题为“本期规律（运营填写）”）。

## 5. 各章节规格

文中 `sc` = 销售额（日均）变化率；`m` = 销售额拆解主因；金额后缀 `/天`（`per` 时）或 `/周`。

### 5.1 本期结论 `sum`

**结论句（`repVerdict()`）**：

```text
无 B：没有对比期数据，本期只对照目标：ACOS a（目标 T），CPA c。下周先做：{行动计划前两项}。
有 B：{规模}，{效率}{原因}。下周先做：{行动计划前两项}。
  规模：|sc| < 2% → “广告销售额[日均]基本持平”；否则 “广告销售额[日均]{增长|下降} x.x%”
  效率：ACOS 为空 → “本期没有广告销售”；≤ 目标 → “ACOS a 仍在目标内”，若比 B 高 ≥ 2pt 加 “，但比 B 期高 n pt”；
        > 目标 → “ACOS a 超出目标 T”
  原因：|m.chg| ≥ 3% 且 |sc| ≥ 2% → “；{下滑|增长}主要来自 {m} {上升|下降} n%”
状态：ACOS 为空、ACOS > T × 1.1 或 sc < −10% → 需处理；ACOS > T 或 sc < 0 → 需关注；否则正常
```

**目标达成（4 格）**：

| 格 | 值 | 参照 | 状态与文字 |
| --- | --- | --- | --- |
| ACOS | A ACOS | 目标 ≤ T · 盈亏线 be | ≤ T 达标；≤ T × 1.1 接近目标；否则超标；> be 文字改为“高于盈亏线”；为空“无销售”（红） |
| CPA | A CPA | 目标 ≤ rules.cpa | 同上三档；为空“无订单”（红） |
| 销售额[日均]变化 | `sc` | 对比 B 区间 | ≥ 0 增长；≥ −10% 小幅下滑；否则明显下滑；无 B “无基准”（灰） |
| 无效花费率 | 最新 14 天 | 参考 10%–20% | ≤ 10% 健康；≤ 20% 偏高；否则过高 |

**关键判断（`repJudg()`，最多 3 条）**：先生成候选，每条有状态与分值（每周金额影响）：

| 候选 | 条件 | 状态 | 分值 | 文案要点 | 跳转 |
| --- | --- | --- | --- | --- | --- |
| 主因 | 有拆解且 `abs(m.chg) ≥ 3%` | `m.v < 0` 需处理，否则正常 | `abs(wk(m.v))` | “CVR 13.03% → 9.85%（−24.4%）是销售额变化的主因，影响约 −$1,989/周。”+ 排查方向（下降时） | 变化归因 |
| 活动集中 | 有 B，存在与总变化同向的活动 | 下滑需处理，增长正常 | 该活动 `abs(wk(dS))` | “下滑集中在 X：销售额日均 −$136，占下滑活动合计的 55%。” | 广告活动 |
| 关键词 | 有新增或消失 | 合计 < 0 需关注，否则正常 | `abs(wk(合计))` | “消失 14 个出单词（−$91/天），新增 10 个（+$71/天），新词还没补上缺口。” | 关键词 |
| 上期动作 | 有上期动作 | 变差 + 需核实 > 见效 → 需关注 | （变差 + 需核实）× 10 | “上期 14 个动作 4 个见效，6 个变差，1 个否定后仍有花费。” | 上期动作复盘 |
| 无效花费 | 无效花费率 > 10% | > 20% 需处理，否则需关注 | 14 天金额 ÷ 2 | “无效花费率 x%（4 周前 y%），近 14 天约 $z 没有带来订单。” | 结构与效率 |
| 机会 | 有收割或提价候选 | 正常 | 收割词每周销售 | “n 个搜索词可收割到精准，m 个投放可提价放量，它们的 ACOS 都在目标内。” | 风险与机会 |

选取：非“正常”的按分值降序取前 2 条（没有“正常”候选时取 3 条），再用“正常”的按分值补足到 3 条。每条右侧有“§NN 章节名”按钮，章节关闭时不显示。

**核心指标**：花费、销售额、订单、ACOS、CVR、CPC 六张卡：A 值、变化（量类在 `per` 时按日均并标“日均”）、近 12 周小图（量类为日均；实心点 = A 所在周，空心点 = B 所在周；ACOS 带目标虚线）。

### 5.2 上期动作复盘 `loop`

- 无 B：“没有对比期，无法回看上期动作”；无动作：“上期没有需要回看的调价或否定”（参考）。
- 标题：`上期 N 个动作：{见效 n 个}，{变差 n 个}，{n 个否定后仍有花费}`（见效绿、变差红）。
- 状态：变差 + 需核实 > 见效 → 需关注，否则正常。
- 正文：分布条（见效 / 持平 / 需核实 / 变差，2px 间隔）+ 图例计数；明细表前 8 条（动作与幅度、对象 + 活动 / 广告组、`[日均]指标 B → A`、结果标签）；超过 8 条提示“另有 n 个动作，见周期优化”；要点：变差 → “本期先复查原因，不要继续同方向加码”；需核实 → “先确认后台已执行；已执行的，说明还有相近搜索词，改用否定词组”；见效 → “当前规则适合这个产品，可以继续沿用”；口径说明：“降价看 ACOS 是否下降；提价看销售变化是否跑赢整体（剔除全账户共同波动）；否定看是否还有花费。”
- 数据来自动作日志（`02` 第 13.7 节）。

### 5.3 变化归因 `why`

- 无拆解：“有因素为 0（如无订单），无法拆解销售额”或“没有对比期，无法拆解变化”。
- 标题：`销售额[日均]{下降|增长} x.x%，主要因为 {m} 从 {B 值} {降|升}到 {A 值}`。
- 状态：sc < −10% 需处理；sc < 0 需关注；否则正常。
- 正文：销售额拆解瀑布图（图注“销售额 = 曝光 × CTR × CVR × 客单价 · 按日均 · 绿色拉动，红色拖累”）；ACOS 拆解因素卡（“ACOS b → a · ACOS = CPC ÷ (CVR × 客单价)”，主因高亮）；要点：
  - 变化 ≥ 5% 的因素按影响排序：“CVR 13.03% → 9.85%（−24.4%，影响 −$284/天）：先排查价格、优惠券、评论、库存与 Listing 等广告以外的原因，再动出价。”
  - 排查方向：曝光 → 预算是否提前用完、出价是否被调低、排名是否下滑；CTR → 主图、价格、评论星级、广告位；CVR → 价格、优惠券、评论、库存、Listing；客单价 → 价格调整、促销、变体结构。
  - 变化 < 5% 的因素合并一条：“曝光、CTR、客单价 变化不到 5%，流量端稳定，问题不在拿量。”
  - ACOS：“ACOS b → a，主要由 {ACOS 主因} {变化} 推动。”
- 链接：在复盘分析中查看花费与 ACOS 拆解。

### 5.4 趋势背景 `trend`

- 标题（按顺序命中）：ACOS 连升 ≥ 2 周 → “ACOS 已连续 n 周上升，是趋势而不是单周波动”（最近 ACOS > 目标为需处理，否则需关注）；日均销售额连降 ≥ 2 周 → 同句式（需处理）；连升 ≥ 2 周 → “日均销售额连续 n 周增长”（正常）；ACOS 连降 ≥ 2 周（正常）；本周日均销售额偏离前 6 周均值 ≥ 15% → “本周日均销售额{低于|高于}前 6 周均值 x%，前几周平稳，先按单周波动处理”（需关注）；否则 “近 12 周走势平稳，本周变化在正常波动范围内”（参考）。
- 正文：三个小图（日均花费、日均销售额、ACOS），卡片右上为最近一周值；A 所在周与 B 所在周加底色；缺日周用空心小点；ACOS 带目标虚线；悬停显示周区间、所属期、值、缺日天数。说明文字与要点：前 6 周均值对比、ACOS 对比目标、“连续 2 周以上同方向变化才按趋势处理；单周异常先排除缺日、归因未补全、促销与断货等外部因素”。

### 5.5 广告活动 `camp`

- 无 B：“没有对比期，无法比较活动变化”。
- 标题：取与总变化同向的活动，按变化绝对值降序累加，直到覆盖 60%（最多 3 个）：`{下滑|增长}集中在 {n 个活动：}{名称…}，占{下滑|增长}活动合计的 x%`。
- 状态：下滑且 sc ≤ −10% 需处理；下滑需关注；增长正常。
- 正文：变化最大的 8 个活动，每行：名称 + 趋势（状态点 + `trendOf()` 文案）、销售额（日均）变化的发散条（以 0 为中线，增长绿向右、下滑红向左）、变化金额、ACOS B → A（A 超目标红）。要点：最多 3 个走坏 / 需关注的活动（带“去调价 →”）；花费占比 ≥ 10% 且效率（销售占比 ÷ 花费占比）< 0.8 的活动最多 2 个。
- 链接：在复盘分析中查看活动 × 周。

### 5.6 关键词 `kw`

- 无 B：“没有对比期，无法判断关键词变动”。
- 标题：净变化 < 0 → `消失 n 个、下滑 m 个关键词，合计 −$x/天；新增与增长补回 +$y/天`（需关注）；否则 `新增 n 个、增长 m 个关键词，合计 +$x/天`（正常）。
- 正文：五张变动卡（新增、增长、下滑、消失、稳定：数量 + 销售额合计；点击带条件跳到关键词页）；两栏“拉动最大 / 拖累最大”（周报 5 个，关键词复盘 8 个；关键词、变动标签、变化金额、主因；点击打开关键词详情）；说明增长 / 下滑口径；要点：出单词数 B → A、前 5 词销售占比 B → A，占比上升 > 5pt 且出单词减少时加“销售越来越依赖头部词…需要靠收割补充新的出单词”。

### 5.7 收割与否定 `term`

- 投放报表：“收割与否定需要搜索词报表”。
- 标题：`n 个搜索词可收割到精准；m 个无效搜索词每周约 $x 没有回报`（有浪费为需关注）。
- 正文：两栏表格（前 8）：可收割（搜索词、订单、ACOS、建议出价）；应否定（搜索词 + 所在活动、点击、花费）。口径说明；要点：品牌词数量（“不直接否定，先检查落地页与竞价”）、收割后加否定精准。链接：在周期优化中确认并导出。

### 5.8 结构与效率 `struct`

- 候选发现（分值越大越优先）：无效花费率 > 20%（需处理，3）；4 周内上升 ≥ 3pt（需关注，2.5）；非品牌 ACOS > 目标且 > 整体 × 1.1（需关注，2）；同词多活动 ≥ 3 个（需关注，1.5）；精准花费占比变化 ≥ 5pt（上升正常 / 下降需关注，1）。
- 标题 = 分值最高的发现；没有发现时 “结构健康：无效花费率 x%，非品牌 ACOS y”（正常）。
- 正文：四张卡（2 × 2）：匹配方式花费占比（B、A 两条堆叠条 + 图例与 A 占比）；品牌 / 非品牌 ACOS（整体、非品牌、品牌词三条横条，目标虚线，超目标红，右侧 B 值）；无效花费率（大数字 + 4 周前 + 金额；12 周柱，最新柱强调色，10%–20% 参考带）；其他信号（同词多活动、星期规律、精准花费占比）。要点 = 其余发现（最多 3 条）。链接：在复盘分析中查看结构与效率。

### 5.9 风险与机会 `ro`

| 风险 | 条件 | 每周金额 | 去处理 |
| --- | --- | --- | --- |
| n 个搜索词高点击无订单 | 有否定候选 | 无效花费 Σ waste | 周期优化 · 否定 |
| n 个投放 ACOS 超标或有点击无单 | 有降价 / 暂停候选 | 可节省 Σ save | 周期优化 · 调价 |
| {主因} 下降 x% | 主因为负且变化 ≥ 5% | 销售影响 `abs(wk(m.v))` | 复盘分析 · A/B |
| n 个活动 ACOS 走坏 | 趋势为需处理的活动 | 超目标花费 Σ max(0, 花费 − 销售额 × T) × 7 / A 天数 | 复盘分析 · 活动趋势 |
| 销售更依赖头部词 | 前 5 占比升 > 5pt 且出单词减少 | — | 复盘分析 · 关键词变动 |

| 机会 | 条件 | 每周金额 | 去处理 |
| --- | --- | --- | --- |
| n 个搜索词可收割到精准 | 有收割候选 | 相关销售 | 周期优化 · 收割 |
| n 个投放可提价放量 | 有提价候选 | 当前销售 | 周期优化 · 调价 |
| n 个新增出单词 | 有新增 | 新增销售 | 关键词页 · 新增 |
| n 个活动走势向好 | 趋势为正常的活动 | — | 复盘分析 · 活动趋势 |

- 标题：`n 项风险、m 项机会；止损空间约 $x/周`（x = 无效花费 + 可节省）。状态：有风险且止损 > 0 需关注；有风险参考；无风险正常。
- 正文：两栏列表（风险红盾图标 / 机会绿色火箭图标），每项：标题、依据、每周金额与类型、去处理按钮；按金额降序（无金额排最后）。说明“金额为按本期数据的粗估，用于排优先级，不是承诺效果”。

### 5.10 下期行动计划 `plan`

动作来自周期优化当前勾选（`repPlan()`），按以下顺序生成：

| 优先级 | 动作 | 对象 | 预计影响 | 去执行 |
| --- | --- | --- | --- | --- |
| 高 | 否定无效搜索词 | n 个 · 否定精准 | 节省约 $x/周 | 周期优化 · 否定 |
| 高 | 超标投放降价 / 暂停 | 降价 n · 暂停 m | 节省约 $x/周 | 周期优化 · 调价 |
| 高 | 排查转化率 / 点击率下滑（主因为 CVR / CTR 且下降 ≥ 5%） | 价格 · 评论 · 库存 · Listing / 主图 · 价格 · 星级 · 广告位 | 影响销售约 $x/周 | 复盘分析 · A/B |
| 中 | 复查上期变差的对象 | n 个 | 先停止同方向加码 | 周期优化 · 准备与回看 |
| 中 | 核实否定是否已执行 | n 个 | 否定后仍有花费 | 同上 |
| 中 | 收割搜索词到精准 | n 个 · 来源活动加否定精准 | 相关销售约 $x/周 | 周期优化 · 收割 |
| 中 | 盈利投放提价 | n 个 · +15% | 花费最多 +$x/周 | 周期优化 · 调价 |
| 低 | 同词多活动收敛（≥ 2 个词） | n 个搜索词 | A 期花费 $x | 复盘分析 · 结构 |
| 低 | 检查预算是否提前用完（趋势为“放量中”的活动） | 活动名 | 放量中 · 报表无预算数据 | — |

- 标题：`下周 n 项动作，预计每周节省约 $x，放量最多增加花费 $y`；没有动作时 “本期没有需要立即执行的动作”。状态：有高优先级 → 需关注。
- 表格列：优先级（高红 / 中琥珀 / 低灰）、动作 + 对象、预计影响、**负责人**（可编辑文本框，默认“运营”）、**复查**（A 结束日 + 7 天）、去执行图标按钮。
- 说明：数量与金额来自周期优化当前勾选（显示是否已完成导出）；复查日后的下次复盘会在“上期动作复盘”自动回看。

### 5.11 经验沉淀 `learn`

| 保持（有则列出） | 改进（有则列出） |
| --- | --- |
| 降价见效 n 个 → “按‘目标 ACOS ÷ 实际 ACOS’降价有效，继续沿用” | 提价后 ACOS 超标或无销售 → “下次提价幅度降到 up/2（至少 5%），或延长观察期” |
| 提价跑赢整体 n 个 → “提价 x%：n 个对象销售跑赢整体，ACOS 仍在目标内” | 提价跑输整体 → “提价没有换来流量，检查预算是否受限、排名是否被挤占” |
| 否定已止损 n 个 | 降价仍变差 → “可能不是出价问题，检查搜索词相关性或直接否定” |
| 无效花费率 ≤ 12% 且未上升 → “每周否定的节奏合适” | 否定后仍有花费 → “导出后在后台抽查执行情况，近似词改用否定词组” |
| 精准花费占比上升 ≥ 3pt → “收割 → 精准的结构在起作用” | 无效花费率 4 周升 ≥ 3pt → “否定频率要跟上拓词节奏” |
| | 头部依赖加重 → “每周固定收割新词，补充出单词池” |
| | 主因为 CVR / CTR 下滑 → “先查非广告因素，确认后再调价，避免误降核心词出价” |

- 标题：`保持 n 条做法，改进 m 条`；改进多于保持为需关注。
- 正文：两栏（保持 / 改进）+ 说明“只有反复出现的规律才写进分析规则，单次现象记在下方补充里继续观察”+ 常显的“本期规律（运营填写）”文本框。

### 5.12 附录 · 数据说明 `appx`

- 标题：`本报告基于{来源}[，A / B 天数不同，量类指标已按日均对比]`（参考）。
- 定义列表：数据范围（A、B 起止与覆盖、缺日、日均说明）、归因滞后（A 期最后 n 天的日期区间）、计算口径（比率重算、LMDI）、判断规则（目标 ACOS 与新品模式、盈亏线、目标 CPA、最低样本、无转化阈值）、未纳入（自然销售与 TACOS、广告位、预算使用率、库存与价格）、人工判断（本轮采纳 / 暂不处理条数）。

## 9. 验收要点

- [ ] 三种类型默认章节与第 2 节一致；关闭的章节不显示、不导出，序号连续。
- [ ] 每节标题都是结论句，数字与图表一致；无 B、投放报表、无拆解等情况显示对应的说明文字。
- [ ] 关键判断最多 3 条，至少一条问题（若存在），跳转到对应章节。
- [ ] A/B 天数不同时，所有量类比较标注“日均”，金额后缀为 /天 或 /周。

- [ ] 历史报告是快照：修改规则或删除归档后，打开历史报告内容不变。
- [ ] 生成中 / 范围更新中 / 更新失败时不能复制、导出、保存。
- [ ] 1440、1024、390 三种宽度及深色模式下无溢出、无文字重叠。
