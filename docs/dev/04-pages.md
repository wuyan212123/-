# 04 · 外壳与页面规格

每个页面按“目标 → 布局 → 交互 → 状态 → 响应式”书写。复盘报告见 `05-report.md`，各状态的文案与处理见 `06-states.md`，样式见 `07-ui-spec.md`。括号中的函数名是原型参照。

## 1. 外壳

### 1.1 左侧导航（`rail()`）

- 品牌区：Logo + “SP 广告工作台 / 3.0 预览版”。
- 分组“分析”：周期优化（角标 = 本周已选动作数，周期完成后不显示）、经营总览、复盘分析、关键词决策、复盘报告。
- 分组“工作区”：数据中心、项目、分析规则。
- 底部：方案说明（正式版改为帮助 / 指标口径）、状态演示（仅原型）、“数据截至 MM/DD”。
- 当前页高亮；≤ 1279px 收为 64px 图标栏，角标改为右上角小圆点数字。

### 1.2 顶栏（`topbar()`）

从左到右：

1. **项目切换**：首字母方块 + 项目名 + “ASIN · 站点”。点开弹层：搜索框（项目名 / ASIN / SKU）、项目列表（覆盖区间、文件数、报告数，当前项打勾）、底部“切换项目会清空高级筛选”+“管理项目”。
2. **范围胶囊**（一个整体，空项目时置灰不可点）：
   - 来源分段：搜索词 / 投放。点击立即生效并请求；悬停说明“一次 A/B 对比只使用一种来源，两种报表不能相加”。
   - A 期按钮：实心 A 徽标 + 日期 + 天数（覆盖不足时显示 “6/7天” 琥珀色，无数据显示“无数据”红色）。
   - “vs”。
   - B 期按钮：描边 B 徽标，同上。
   - 筛选按钮：有筛选时显示数量。
   - 范围已改未生效时，对应按钮右上角显示黄点。
3. **状态胶囊**：结果已更新 HH:MM（绿）/ 正在更新…（转圈）/ 更新失败 · 重试（红，可点）/ 暂无数据（空项目）。悬停显示当前显示的范围。≤ 1499px 只留图标。
4. 右侧：数据截至 MM/DD（≤ 1100px 隐藏）、⌘K 搜索按钮（≤ 1439px 只留图标）、“指标口径”问号按钮。

### 1.3 日期弹层（`popDate()`）

三栏：预设 | 日历 | 归档周。

- 预设分组见 `02` 第 2 节；B 弹层顶部多一组“相对 A”。当前选中的预设高亮。
- 日历：月份切换；选择方式为“先点开始、再点结束”（第二次点早于开始则交换）；样式标出范围内、开始、结束、另一期范围（灰底）、缺日（红色删除线，悬停“缺日：该日无数据，不补零”）、超出数据范围（置灰）、数据截至日（绿点）。日历下方有两个日期输入框可直接输入。
- 归档周：W 周号 + 起止，点选即设为该周。
- 底部说明：“最近 4 周 = 截至日所在周往前共 4 个自然周；此前 28 天基准 = A 开始日前连续 28 天，用于周均与比率对照。日期首尾均计入。”
- 底栏：覆盖摘要（“7 天 · 已覆盖 6 天 · 缺 10/12”，无数据时红字“所选范围没有数据”）、取消、应用。A 期所选范围没有数据时“应用”禁用。
- B 弹层靠右对齐；手机为底部面板。

### 1.4 筛选弹层（`popFilters()`）

标题“分析范围筛选 · 影响总览、清单、报告与 Excel 导出”。广告活动、广告组（多选标签）、匹配方式（自动 / 广泛 / 词组 / 精准 / ASIN）、投放（包含）文本、精确搜索词文本。底栏：清空、取消、应用筛选。打开时复制当前筛选为草稿，应用后才请求。

### 1.5 手机范围面板（`popScopeMobile()`）

顶栏只剩项目切换与“范围摘要”按钮（日历图标 + A 日期 + 筛选数，未生效时黄点）。点开底部面板：来源分段、A 期按钮、B 期按钮、高级筛选按钮、“数据截至 · 更新状态”。

### 1.6 横幅（`banners()`）

页头下方，按需出现：

| 横幅 | 条件 | 内容与操作 |
| --- | --- | --- |
| 更新中 | `loading` | “正在更新到新范围 A … · B …。下方仍是上次结果（A … · B …），更新完成前不能导出。” |
| 更新失败 | `error` | 失败原因 + 实际显示的范围 + “旧结果不能作为新范围导出”；按钮：恢复为显示范围、重试 |
| 无 B 基准 | `!hasB` | “B 期 … 没有可用数据。新增、消失和提升等对比判断已暂停，只按目标阈值给出提示。”；按钮：调整 B 期 |

覆盖不足不用整行横幅，而是在页头元信息末尾放“覆盖不足 · A x/y 天 · B x/y 天 · 已按日均对比”标记，点开弹层看缺日与口径（`covChip()`、`popCov()`）。

### 1.7 命令面板（`cmdPalette()`，新增）

⌘K / Ctrl+K 或 `/` 打开。输入即过滤，分组显示：

- 关键词（有输入时，最多 6 个，显示 A 花费与首个标签）→ 打开关键词详情；
- 页面（9 个）；
- 操作：打开风险词清单、A 设为最近 7 天 / B 前 7 天、切换来源、复盘：活动趋势 / 关键词变动 / 结构与效率、生成本期复盘、导入报表、查看指标口径、切换到其他项目。

↑↓ 选择，Enter 执行，Esc 关闭。

### 1.8 其他

- Toast：底部居中，2.8 秒自动消失，带图标。
- “指标口径”对话框：指标计算表、四种空值、颜色语义（见 `02` 第 1 节）。
- 底部标签栏（手机）：优化、总览、关键词、报告、更多（弹出其余页面）。

## 2. 周期优化（`vCycle()`，默认首页，新增）

**目标**：按资深运营的每周节奏完成一轮可回看的关键词优化。

**页头**：“第 N 周 · 关键词周期优化”（N = A 结束日的 ISO 周）；元信息：项目 · 决策窗口 A（天数）对比 B · 来源 · 覆盖标记；操作：生成本周复盘、导出本周动作 · n（跳到“确认导出”）。周期完成后显示“本周期已完成”。

**步骤条**：6 个步骤卡片，每张显示序号（完成后为对勾）、副标题、步骤名，收割 / 否定 / 调价 / 确认导出显示已选数量。可直接点任意步骤；离开的步骤记为完成。手机横向滚动并让当前步骤居中。

**主体 + 右侧“资深做法”说明栏**（`guide()`，≤ 1279px 移到下方）。底部吸附操作栏：左侧本步摘要，右侧“上一步 / 下一步：xx / 完成本周期”。

| 步骤 | 主体内容 |
| --- | --- |
| 1 准备与回看 | “决策窗口检查”清单（`02` 第 13.1 节，每条带通过 / 注意图标、说明与操作按钮）；“上期动作回看”：汇总卡（上期动作、改善 / 已止损、持平、变差、需核实执行）+ 明细表（动作、对象、活动 / 广告组、执行前 B、执行后 A、结果）+ “只作方向参考”说明 |
| 2 诊断 | 本期结论卡（`insight()`）；活动表现表（A 日均花费、日均变化、A 销售额、ACOS、近 8 周 ACOS 小图带目标虚线、判断、趋势说明、待处理数、“处理 →”跳到调价并筛选该活动）；关键词变动计数（新增 / 增长 / 下滑 / 消失）+ 跳转复盘分析 |
| 3 收割 | 搜索词报表才可用（否则横幅提示切换）。表格：勾选、搜索词 → 去向、来源（活动及匹配，悬停列出全部）、点击、订单、ACOS、每次点击收入、建议出价（下方小字当前 CPC）、置信度。全选框。空状态“本周没有符合条件的收割词” |
| 4 否定 | 表格：勾选、搜索词、所在活动 / 广告组 · 匹配、点击、花费、每周浪费、方式（否定精准 / 否定 ASIN / 人工复核 · 品牌词）与说明、置信度 |
| 5 调价 | 分桶页签（亏损降价 / 无单降价 / 暂停 / 盈利提价 / 维持 / 观察，带数量）+ 活动筛选标签；表格：勾选（只有前四类可勾选）、投放 / 定向（匹配、活动 / 广告组）、点击、订单、ACOS、每次点击收入、建议幅度与参考出价（下方当前 CPC）、依据与置信度。说明“报表不含当前出价，参考出价 = 当前 CPC × (1 + 幅度)” |
| 6 确认导出 | 6 张汇总卡（收割、否定、降价 + 暂停、提价、预计每周节省、已采纳的人工判断）；批量操作表预览（前 14 行 + “另有 n 行”）与“导出动作日志 / 导出批量操作表”；上传后核对清单（4 项）。“完成本周期”写入动作日志 |

在任何步骤点关键词名，底部抽屉打开关键词详情（同关键词页详情）。

## 3. 经营总览（`vOverview()`）

**目标**：打开后先回答“表现怎样、为什么、先看哪里”。

**页头**：标题 + “项目 · 来源 · A 对比 B · 覆盖标记”；右侧本轮进度条（数据截至 ✓、A/B 已设定 ✓、周期优化第 n/6 步、生成复盘）与“打开关键词清单 →”。

**布局**：

1. **KPI 条**（6 张卡，也是下方趋势图的页签）：广告花费、广告销售额、广告订单、ACOS、CVR、CPC。每张：名称（当前选中加“图表中”）、A 值、变化（`per` 时为日均变化并标“日均”）、副文本（B 值或日均对照）、A / B 逐日小图。悬停说明（如“花费上涨本身不代表变差”）。无 B 时变化显示“无基准”。
2. 第一行两栏：左 = **本期结论卡** + **每日趋势**（所选指标；A、B 期底色带与“A 期 / B 期”标签；缺日竖虚线与“缺”；悬停十字线 + 提示框显示日期、星期、所属期、四个指标）；右 = **需要优先处理**（风险 / 机会 / 提示三组，每项：图标、名称、说明、数量、金额、已处理数，点击带标签进入关键词页并保留范围）。
3. 第二行两栏：左 = **重点关键词**（A 花费前 8：关键词、标签、A 花费（行内条）、近 8 周花费小图、A ACOS、销售额变化、建议；“全部 n 个词 →”）；右 = **数据覆盖与口径**（来源、A 期、B 期及缺日、此前 28 天基准、明细行数与词数）+ **最近复盘**（2 条历史 + “生成本期复盘”）。

≤ 1279px：KPI 3×2，两栏变单栏。手机：KPI 2×3。

## 4. 复盘分析（`vDiagnosis()`、`vReview()`）

**页头**：“复盘分析”+ 元信息（A/B 页签显示“与之前相比发生了什么”，其他页签显示“近 12 周 · 按 A 期结束日 MM/DD 倒推的 7 天区间”）+ 来源 + 覆盖标记；操作“生成周期对比报告”。下方 5 个页签：A/B 对比、活动趋势、关键词变动、结构与效率、星期规律；右侧提示“沿用顶部分析范围与筛选”。在本页点关键词名，用底部抽屉显示详情。

### 4.1 A/B 对比

- **模式**：自定义 A/B（直接用顶部 A/B 按钮）/ 归档周期（A、B 各选一个归档周，应用）/ 大促前后（活动开始日 + 前后 7 / 14 / 28 天，A = [开始日, 开始日 + n − 1]，B = [开始日 − n, 开始日 − 1]，应用）。应用即改写顶部范围并请求。
- **变化拆解**：瀑布图（B 期总额 → 各因素贡献 → A 期总额），分段切换销售额 / 花费 / ACOS；纵轴截取到有变化的区间，被截断的总额柱画断轴记号；说明 LMDI 与颜色含义。
- **指标对照**（左）：11 项指标 × A 合计、B 合计、变化、A 日均、B 日均、日均变化（比率不做日均，显示“比率”）。
- **变化来自哪些词**（右）：按销售额 / 花费 / 订单切换，贡献绝对值最大的 12 个词的发散条（A 高于 B / A 低于 B），点击打开详情。
- **A/B 逐日对照**：花费、销售额、订单、ACOS 四个小图，按第 N 天对齐，A 实线、B 虚线，缺日留空。
- **覆盖与统计口径**（折叠）：日期、缺日、来源、比率、重叠、28 天基准六条说明。

### 4.2 活动趋势

- **活动 × 周热力表**：指标分段（ACOS / 花费 / 销售额 / 订单 / CVR / CPC）；表头标出 A、B 所在周；缺日周圆点；末列周环比；末行“全部活动”。着色规则见 `02` 第 10.4 节；图例随指标切换。
- **趋势判断**（左）：按 bad → warn → good → neu 排序的活动列表，显示 `trendOf()` 文案与最近一周 ACOS；bad / warn 带“去调价 →”（跳到周期优化调价步骤并筛选该活动）。
- **花费占比 vs 销售占比**（右）：每个活动两条并列条与效率值（≥ 1 绿，< 1 红），说明“效率 < 1 是预算再分配时优先削减的对象”。

### 4.3 关键词变动

- 5 张分桶卡（新增、增长、下滑、消失、稳定）：数量 + 销售额合计变化（`per` 时 /天）；点击筛选下方清单，再点取消。
- **变动清单**：默认显示变动最大的非稳定词前 20（可“显示全部”）；列：关键词、变动、销售额 B → A（日均）、变化、订单 B → A、ACOS B → A、主因、近 12 周订单小柱；右上分布条；“在关键词决策中处理 →”（带变动条件跳转，按变动排序）。
- **头部关键词 × 周**：近 12 周销售额前 20 的词，指标分段（订单 / 销售额 / 花费 / ACOS）。
- **集中度**：前 1 / 5 / 10 个词、长尾词的销售占比与出单词数，A / B 并列条 + 解读。

### 4.4 结构与效率

- **匹配方式结构**：每周花费占比堆叠柱（12 周，A 所在周标出）+ 表格（花费占比 A / B、销售占比 A、ACOS A、变化）+ 精准占比解读。
- **品牌 / 非品牌**（左）：整体 ACOS、非品牌 ACOS（高亮）、品牌词 ACOS 与花费占比 + 类型表（词数、花费占比、销售占比、ACOS A、变化）。
- **无效花费率**（右）：最新值、4 周前、约金额 / 14 天；12 周柱图，10%–20% 参考带；说明参考带不是行业标准。
- **效率分层**（左）：花费 × ACOS 散点（平方根横轴、目标 ACOS 虚线、目标 CPA 竖虚线、两个象限注释、点击圆点打开详情）+ 分组图例与数量。
- **同词多活动竞价**（右）：搜索词报表下的前 5 个，显示每个活动的匹配、ACOS、订单，绿框为建议保留；投放报表下提示切换。

### 4.5 星期规律

- **星期 × 指标热力表**：周一…周日（每列显示天数）× 日均花费、日均销售额、日均订单、CVR、CPC、ACOS + 8 周均值列。量类单色色阶；比率以均值为中点双色，蓝色为有利。可勾选“排除异常日（日期列表）”。
- **规律**：CVR 最高与最低的星期及差距、ACOS 最高的星期、是否值得按星期调整（差异 < 10% 不建议）。
- **数据边界**：按日报表只能看星期规律；分时需要 Amazon Marketing Stream 等小时级数据（新增范围）；后台没有原生分时调价。

## 5. 关键词决策（`vKeywords()`）

**目标**：快速扫描一批词，再深入核查少量对象。表格是主体。

### 5.1 页头

标题 + “来源 · A vs B · n 个词 · n 行活动明细 · 覆盖标记”；操作：生成复盘、导出 Excel ▾（弹层说明导出范围，见 `02` 第 14 节；`loading/error` 时禁用并提示原因）。

### 5.2 视图与变动

- **视图标签**：全部 / 风险 / 机会 / 提升 / 需核查 / 已处理，各带数量（`02` 第 5.3 节）；右侧常驻提示“清单视图不影响分析范围与导出”。
- **变动条**（常驻）：全部 / 新增 / 增长 / 下滑 / 消失 / 稳定（数量按当前视图过滤后计算；无 B 时置灰显示“—”）；右侧“A 对比 B · 按日均 · 按”+ 依据分段（销售额 / 订单 / 点击 / 花费）。悬停说明各桶规则。

### 5.3 工具栏

搜索（“在清单中搜索词或活动”）、标签下拉（按 风险 / 机会 / 建议：转 Exact / 变化 / 需核查 分组，带数量；选中后显示清除按钮）、订单分段（全部 / 有订单 / 无订单）、B 列显示（B 值 / 变化）、行高（舒适 / 紧凑）、显示列（n/30）。勾选任意行后，工具栏替换为**批量操作条**：已选 n 个词、标记为已采纳、暂不处理、复制关键词、取消选择。

### 5.4 表格

**列定义**（`COLDEF`，共 30 列，偏好存浏览器）：

| 分组 | 列（id，默认宽度） |
| --- | --- |
| 身份 | 关键词 `kw` 270（固定，不可隐藏）、标签 `tags` 200、匹配 `match` 96 |
| 判断 | 变动 `move` 128、建议操作 `sugg` 150 |
| A 分析期 | 曝光 `A_impr` 96、点击 84、花费 104、销售额 104、订单 84、CTR 84、CVR 84、CPC 84、ACOS 84、ROAS 84、CPA 84 |
| B 对比期 | 同 A，id 前缀 `B_` |
| 上下文 | 广告组 `adgroup` 170、投放词 `target` 190、关键词类型 `kwtype` 104 |

默认显示（`DEF_COLS`）：关键词、标签、变动、匹配、A 点击、A 订单、A 花费、A ACOS、B 点击、B 订单、B ACOS、建议。旧偏好里没有“变动”列的，首次加载时自动插在“标签”之后（只迁移一次）。

**单元格**：

- 关键词：勾选框、展开箭头（来源活动）、词名（单行省略，悬停全文）；下方小字：人工判断徽标 · n 个活动 · 类型 · “活动间分化”（琥珀）。
- 标签：最多 2 个 + “+N”，悬停列全部。
- 变动：类型徽标 + 变化百分比（消失不显示百分比）；悬停“销售额（日均）：B … → A …”。无 B 显示“无基准”。
- 匹配：单一显示中文名；多个显示“n 种 自动/广泛”。
- A 花费、A 销售额：数值 + 本页最大值比例的细条。
- A ACOS：> 目标红，≤ 目标 70% 绿。
- B 列：次级色；B 列显示切到“变化”时显示 `dlt()` 徽标，列宽至少 112。
- 建议：彩点（机会绿、高优先红、其他琥珀）+ 首条动作 + “×n”（同动作条数）+ “+m”（其他动作）；无建议时“观察”（样本不足）或“—”。
- 广告组 / 投放词：多个时显示“n 个广告组”“n 个 · 首个”，悬停列全部。

**表头**：A / B 列头带实心 A / 描边 B 徽标（变化模式下 B 显示 Δ）；点击排序（文本列首次升序，其余首次降序，再点切换），空值始终排最后；当前排序列显示箭头；右缘拖动调整列宽（70–520px），聚焦拖柄后 ← → 每次 16px；首列表头有“本页全选”。表头吸顶，表格在自己的容器内横向 / 纵向滚动。

**行状态**：打开详情的行高亮；关闭详情后，刚看过的行左侧保留浅色标记并滚回该行；勾选行浅色底。

**来源活动展开**（`subTable()`）：在原行下方插入子表（固定在可视宽度内）。标题“来源活动 · 出现在 n 个活动、m 个广告组 · 汇总标签用于发现问题，操作请以每个活动的数据为准”。列：广告活动、广告组、投放（投放报表下为搜索词）、匹配、A 点击、A 花费、A 销售额、A 订单、A ACOS、A ROAS、B 点击、B 花费、B 订单、B ACOS、活动级判断（标签 + 该行建议）。底部合计行，并校验“活动加总与汇总行一致”（花费差 < 0.005、点击与订单相等时显示绿色对勾，否则警告）。

**页脚**：“第 a–b 个，共 n 个词（范围内 m）”、恢复列宽（有自定义宽度时）、快捷键提示（J K 上下、↵ 详情、X 选择）、每页 20 / 50 / 100、页码（最多 5 个）。

**空清单**：“当前清单视图下没有词。分析范围内共有 n 个词；视图、标签、搜索和订单筛选只影响清单显示。”+ 清除清单筛选。“已处理”视图为空时：“还没有处理过的词。在关键词详情里采纳或暂不处理建议后，会出现在这里，并写入本期复盘。”

### 5.5 详情侧栏（`detail()`）

1440 并排 432px；1024 覆盖在表格右侧；手机全屏。

- **头部**：类型标签、位置“i / n”（按当前清单排序）、上一个 / 下一个（跨页时自动翻页）、关闭（Esc）；词名（完整显示）；上下文“来源 · n 个活动 · m 个广告组 · 匹配方式”；人工判断徽标与全部标签。
- **建议与依据**：每条建议一张卡：动作、“建议动作 · 需人工确认”、优先级；对象路径（活动 › 广告组 › 投放 · 匹配）；事实、命中规则（逐条带图标）、风险。无建议时说明原因（样本不足保持观察）。
- **A / B 指标**：花费、销售额、订单、ACOS、点击、CVR 六张卡（A 值、B 值、变化、A/B 对比条）；该词的销售额拆解因素卡；“查看全部 11 项指标”展开表。
- **近 12 周**：花费与订单两组周柱（截至 A 结束日），零值用浅色。
- **来源活动**：每行活动、A 花费 · 订单 · ACOS、广告组 · 投放 · 匹配、首个标签；“在表格中展开 / 收起”。
- **我的判断**（新增）：提示需综合判断的业务因素（产品相关性、毛利、库存、推广阶段）；按钮“采纳「首条建议」，写入复盘”“暂不处理”；已判断时显示徽标、动作、时间与“撤销”。说明“记录只写入本期复盘；调整请到亚马逊广告后台执行，本工具不会提交任何改动”。
- **底栏**：复制关键词、写入复盘（跳转报告，类型为关键词复盘）、返回清单。

## 6. 数据中心（`vData()`）

- **导入报表**：步骤指示（选择文件 → 识别类型与日期 → 预览变化 → 确认导入 → 查看结果）；拖放区（支持 .xlsx / .xls / .csv、多文件；说明“搜索词报表、投放报表 · 按日或历史周期 · 中英文列名”）。
- **预览**：每个文件一张卡：文件名、识别类型、粒度、日期范围与天数、行数、状态（可导入 / 需补充范围）；新增 / 更新 / 未变 / 拒绝 计数；拒绝原因（带行号）；重叠说明；缺日期的文件提供起止日期输入。底部说明“本次文件中没有出现的旧记录不会被删除。原文件与来源行号会保留”，按钮“取消 / 确认导入 n 个文件（跳过待补充文件）”。
- **导入中 / 完成 / 失败**：横幅。完成：“新增 · 更新 · 未变 · 拒绝；数据现已覆盖至 MM/DD，A/B 默认范围已更新”+ 继续导入 / 查看总览。失败：“导入失败，未写入任何数据”+ 原因（文件名、行、缺少的列）+ 返回预览 / 重新选择。
- **数据覆盖**（新增展示）：搜索词报表、投放报表各一行，每格一天，缺日红框、无此类报表浅灰；下方月份刻度。
- **原文件归档台账**：文件名、报表类型、日期范围、粒度、覆盖天数、周期数、行数、上传时间、状态（已归档 / 有缺日 + 说明）、删除。
- **删除归档**：独立确认对话框，写明后果（移除 n 条明细、该区间变为缺日或回退到其他文件、总览 / 诊断 / 清单 / 导出立即变化、已保存报告正文不受影响），勾选“我了解删除后无法撤销”后才能点红色“删除归档”。

## 7. 项目（`vProjects()`）

- 页头：搜索（项目、ASIN、SKU）、新建项目。
- 表格：项目（当前项目加“当前”标签）、产品、站点、ASIN / SKU、数据覆盖（区间 · 天数 + 覆盖条，未导入显示“未导入报表”）、文件数、报告数、备注、操作（进入、编辑、删除）。
- 新建 / 编辑对话框：项目名称、产品名称、站点（下拉）、ASIN、SKU、备注。
- 删除对话框：写明将一并删除的归档文件数与明细、报告数、项目规则；共用的 AI 配置不受影响。
- 无项目：空状态“还没有项目”+ 新建项目。

## 8. 分析规则（`vRules()`）

- 页头：“项目级规则 · 仅作用于「项目名」”；有修改时显示“有未保存的修改”，按钮“放弃修改 / 保存并重算”（无修改时禁用）。保存后提示“规则已保存，分析结果已按新规则重算”。
- **目标与阈值**：目标 ACOS（%）、目标 CPA（币种）、最低点击样本、CTR 判断最低曝光、无转化点击阈值、变化阈值（%），每项带一句用途说明；**新品模式**开关（说明放宽幅度）。
- **周期优化参数**（新增）：盈亏平衡 ACOS、收割最少订单、盈利提价幅度、无单阶梯降价、单次降价上限、排除最近未结算天数。（待决：收割去向活动配置，见 `08`）
- **保护词表**：品牌词、竞品词，标签输入（回车添加、× 删除），说明“命中的词不会被建议直接否定，改为人工复核”。
- **AI 配置**（所有项目共用）：服务商、模型、API Key（掩码）；状态“配置已保存 · 尚未验证连接”或“连接测试通过”；测试连接；说明发送内容与“关闭 AI 不影响任何分析功能”。
- **字段映射说明**（折叠）：系统字段 / 中文列名 / 英文列名，含“销售件数与广告订单区分”。
