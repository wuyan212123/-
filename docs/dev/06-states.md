# 06 · 状态矩阵

原型左下角「状态演示」可以逐个查看前 12 种状态。每个页面完成前，按本表逐项核对。

## 1. 全局与数据状态

| 状态 | 触发条件 | 表现 | 操作 | 导出 / 报告 |
| --- | --- | --- | --- | --- |
| 无项目 | 没有任何项目 | 顶栏只有“未选择项目 · 新建项目后开始分析”；分析页、数据中心、分析规则显示空状态“还没有产品项目：项目对应一个产品，保存它自己的报表、分析规则和复盘报告。先建一个项目，再导入广告报表。” | 新建项目 | 不可用 |
| 空项目 | 项目没有任何导入数据 | 范围胶囊置灰；状态胶囊“暂无数据”；分析页空状态“这个项目还没有导入报表”（说明导入后自动按最近 7 天对比前 7 天展开）+ 支持格式标签 | 导入报表、查看示例项目 | 不可用 |
| 当前范围无数据 | 范围内没有任何明细（筛选过窄或日期在数据外） | 空状态“当前范围没有匹配记录”+ 范围摘要（来源 · A · B · 筛选数，精确搜索词另列）+“数据在这个范围内为空，并不代表真实零值” | 清除筛选（有筛选时）、改为最近 7 天对比前 7 天 | 不可用 |
| 清单筛选为空 | 清单视图过滤后为 0 | 表格内空行：“当前清单视图下没有词。分析范围内共有 n 个词；视图、标签、搜索和订单筛选只影响清单显示。” | 清除清单筛选 | 导出不受影响（仍导出全部） |
| “已处理”视图为空 | 本期没有人工判断 | “还没有处理过的词。在关键词详情里采纳或暂不处理建议后，会出现在这里，并写入本期复盘。” | 清除清单筛选 | — |
| 没有历史基准 | B 覆盖天数为 0 | 页头下警告横幅（见 `04` 第 1.6 节）；KPI 与 B 列显示“无基准”；变动条置灰；拆解、上期回看、报告相关章节显示“没有对比期…”；标签只给按目标阈值的判断 | 调整 B 期 | 可用 |

| 正在更新 | 已应用新范围，请求进行中 | 状态胶囊转圈“正在更新…”；范围按钮黄点；横幅“正在更新到新范围 …。下方仍是上次结果 …，更新完成前不能导出。”；关键词表半透明 | — | **禁用** |
| 更新失败 | 新范围请求失败 | 状态胶囊“更新失败 · 重试”；横幅写失败原因与实际显示的范围、“旧结果不能作为新范围导出” | 恢复为显示范围、重试 | **禁用** |
| 读取失败 | 首次读取分析结果失败（服务无响应） | 空状态“读取分析结果失败：本地分析服务没有响应（127.0.0.1:8001）。你的项目和已导入数据不受影响。” | 重试 | 不可用 |

## 2. 导入状态（数据中心）

| 状态 | 表现 | 操作 |
| --- | --- | --- |
| 待选择 | 拖放区 | 选择文件 / 拖入 |
| 导入待确认 | 每个文件的预览卡（类型、粒度、日期、行数、新增 / 更新 / 未变 / 拒绝、拒绝原因与行号、重叠说明）；缺日期的文件显示“需补充范围”与日期输入 | 取消、确认导入 n 个文件（可跳过待补充文件） |
| 导入中 | 横幅“正在导入 n 个文件，完成后分析结果会自动按新数据更新…” | — |
| 导入完成 | 绿色横幅：新增 · 更新 · 未变 · 拒绝；“数据现已覆盖至 MM/DD，A/B 默认范围已更新” | 继续导入、查看总览 |
| 导入失败 | 红色横幅：“导入失败，未写入任何数据。{文件} 第 n 行无法识别为{类型}（缺少“…”列）。可检查导出设置后重新选择文件。” | 返回预览、重新选择 |
| 删除归档确认 | 对话框写明影响的明细行数与后果；勾选“我了解删除后无法撤销”后删除按钮才可用 | 取消、删除归档 |

## 4. 文案原则

- 说明发生了什么、影响是什么、可以怎么做；不道歉，不用含糊的“出错了”。
- 区分“无数据 / 无匹配记录 / 真实 0 / 不可计算”。
- 涉及广告后台的动作一律写“导出”“到后台执行”，不写“执行”“已应用”。
- 状态不只靠颜色：同时有图标与文字（例如“覆盖不足”标记、结果标签、优先级标签）。
