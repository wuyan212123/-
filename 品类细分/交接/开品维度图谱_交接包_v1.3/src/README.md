# 品类开品维度图谱

把一个品类拆成三块，用于开品前的筛选：

1. **在售类型（已观察）**：市场上现在主要卖的商品类型。每个类型附示例商品、对应维度（带来源标记）、优缺点、升级方向、机会判断和新品属性清单。
2. **分类维度**：所有维度和取值，按“产品本体 / 销售形态 / 市场定位”分组，标 L1 / L2 / L3 / 门槛。
3. **缺口与机会（假设）**：六项评分算出 A / B / C 优先级；证据不足的列为线索，核实后不成立的列为已排除。

另有白地图（维度交叉的供给与需求）、类型档案、对照表和“方法与规则”。

已完成品类（数据快照 2026-11）：

- 针管笔、水彩本
- 颜料系列（4 个体系，各自独立成品类）：水彩颜料 `wc`、水粉颜料（含果冻杯）`gouache`、丙烯颜料 `acrylic`、油画颜料 `oil`
- 画架系列（7 个品类）：落地画架 `easelFloor`、桌面画架 `easelTable`、户外写生画架 `easelPlein`、儿童画架 `easelKids`、展示画架 `easelDisplay`、画箱 `artBox`、画柜 `artCabinet`

同一系列的品类写了 `series:"颜料"` 或 `series:"画架"`：标签栏里归在对应系列（如“颜料系列”）下面，导图上方显示系列总览卡片（每个体系的定位、规模和 A / B 机会，点卡片切换）。

## 规范

所有品类按 [开品维度图谱规范](../开品维度图谱规范.md) 执行，样板为水彩本（`categories/book.js`）。`check.js` 会按规范的最低要求检查（维度三组、≥ 14 个维度、≥ 5 个类型、机会 2 打分 + 1 线索 + 1 已排除、4 张白地图且含价格带）。

## 新增一个品类

1. 复制 `src/categories/_template.js` 为 `src/categories/<英文id>.js`，按注释填写。
2. 在 `src/build.py` 的 `ORDER` 里加上这个 id（决定标签顺序）。
3. 运行：

```bash
python3 品类细分/src/build.py
node 品类细分/src/check.js
```

单独导出：`python3 品类细分/src/build.py book` 只打包水彩本；`python3 品类细分/src/build.py 颜料` 打包整个颜料系列（生成 `颜料系列_开品维度图谱.html`），`build.py 画架` 同理。

`check.js` 会检查维度名、类型名、机会名、参考商品和来源的引用是否写对，以及评分是否完整、白地图行列数是否一致。全部通过后再发布。

## 调研流程（页面“方法与规则”里有完整版）

1. 定边界：定义、纳入、不纳入、邻近品类。
2. 采样 SKU：两个市场各 30–50 个，覆盖畅销头部、白牌主力、品牌代表款、新上架款。
3. 拆维度，按三组归类，同组内不重叠。
4. 规范取值：型号、标称规格、实测规格分开；未披露记“未知”。
5. 维度分层：L1 / L2 / L3 / 门槛。
6. 归纳在售类型：先按结构分组，再标市场体量。
7. 写类型档案。
8. 画白地图（至少 3 张），供给和需求分开标。
9. 机会评分与排序；线索、已排除单独列出。
10. 用验证关键词查搜索量和 Top 50 竞品，回填评分。

## 数据说明

- 价格、评分、徽章是页面快照，以链接实时页面为准。
- 没有接入实时销量数据。需求信号和机会评分是根据公开信息的判断，拿到卖家精灵 / Helium 10 数据后应回填。
