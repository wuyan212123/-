品类开品维度图谱

把一个品类拆成：① 市场上现在主要卖的商品类型；② 所有分类维度和取值；③ 现有类型之间的缺口和开品机会。每条结论都标了依据和来源类型，可以直接用来做开品立项前的筛选。

依据怎么来的：在售商品页面、品牌官网规格、畅销榜标签、评测和差评。没有实时销量数据，竞争程度、需求信号和机会评分是根据这些公开信息做的判断，每个机会都附了验证方法，开品前需要用卖家精灵 / Helium 10 / 生意参谋跑一遍。

白地图

用关键维度两两交叉，看每个组合现在的供给和需求。供给分红海、有供给、稀少、空白、不成立五级；需求信号单独标（● 越多越强，? 待验证）。只有供给稀少或空白、且需求中等以上才算机会格（绿框）；供给少但需求没证据的标“待验证”。点任意一格可以看到 1–3 个参考链接、判断依据和验证关键词。

类型档案

每个在售类型一张卡，按结构分组：结构示意、示例商品、优缺点、新品必须具备和必须避免的点。点类型名会在思维导图里展开它。示意图是结构示意，不是实拍。

竞品品牌

这个品类里主要的竞品品牌：定位、代表产品、价格带、渠道、主打卖点，以及各自覆盖哪些在售类型。矩阵里的圆点 = 该品牌有这一类型的在售产品（按本轮调研样本，不代表品牌全部产品线）。点品牌名或类型名会在思维导图里定位。

类型对照表

一行一个在售类型，方便横向比较。点任意一行会在思维导图中定位。

机会评估

每个机会按 6 项打分（1–5 分），加权得到总分，再按总分定优先级：A ≥ 3.5，B ≥ 3.0，其余为 C。证据不足、还不能打分的列为“线索”；核实后不成立的列为“已排除”并写明原因，避免以后重复调研。评分是根据公开信息的判断分，拿到搜索量和竞品数据后应替换。

方法与规则

这一节是通用方法，套用到新品类时照着走。最后一张卡是当前品类的专用规则。

新品类套用流程

  1. 定边界写清品类定义、纳入、不纳入和邻近品类，避免把邻近品混进来。
  2. 采样 SKU两个市场各采 30–50 个在售 SKU：畅销榜头部、白牌主力、品牌代表款、新上架款都要有。
  3. 拆维度把每个 SKU 的属性拆开，按“产品本体 / 销售形态 / 市场定位”三组归类，同组内不重叠。
  4. 规范取值统一单位和口径，型号、标称规格、实测规格分开，未披露记“未知”。
  5. 分层每个维度标 L1（定义品类）/ L2（规格变体）/ L3（卖点差异）/ 门槛（合规）。
  6. 归纳类型用 L1 + 关键 L2 组合出在售类型，先按结构分组，再标市场体量。
  7. 写档案每个类型：示例商品、维度映射（带来源标记）、优缺点、升级方向、机会判断、新品清单。
  8. 画白地图至少 3 张：两个 L1 交叉、类型 × 价格带、场景 × 卖点。供给和需求分开标。
  9. 评分与排序机会按 6 项打分定优先级；线索和已排除单独列出。
  10. 数据验证用验证关键词查搜索量和 Top 50 竞品，回填需求信号和评分。

数据登记规则

  1. 最小单位是一个在售 SKU；套装里的每一支 / 每一本单独记录属性。
  2. 型号代码、标称规格、实测规格分开登记，绝不混用。
  3. 每个属性标注来源：厂家声明 / 卖家宣称 / 第三方评测 / 未披露 / 推断。未披露就记“未知”，不根据外观推断。
  4. 卖家宣称和实测分开。新品的卖点写进 listing 之前必须实测。
  5. 数量口径分开记：每件内含数量、每单件数（几本装 / 几套装）、SKU 总数量、配件件数。工具件数不等于主品数量。
  6. 商品状态分开：在售 / 缺货 / 停产余货。价格、评分、徽章记快照日期。
  7. 已观察（①）和假设（③）分开。被核实推翻的假设保留在“已排除”里并写明原因。
  8. 用途标签可以多选（一个 SKU 可以同时属于多个场景）。

维度分层与混装框架

L1定义品类：取值不同就是不同的品，决定子类目和人群。 L2规格变体：决定 SKU 和变体结构。 L3卖点差异：决定溢价、listing 卖点和差异化。 门槛合规门槛：不满足就不能卖。
混装方式（通用）
  • 同规格补货装：完全相同的规格重复多件。
  • 单维度混装：只有一个维度不同（如同色不同粗细、同纸不同尺寸）。
  • 多维度混装：两个以上维度同时不同（如多粗细 + 多笔头）。
  • 跨工具组合：搭配其他品类的工具，主品数量和工具件数分开记。

来源标记与依据强度

厂家品牌官网或官方规格明确写出。 卖家商品页标题或描述里的宣称，未经独立验证。 评测第三方评测、论坛实测或大量买家评价印证。 未披露页面没写，记为未知，不推断。 推断根据同类产品和常识的判断，需要验证。
依据强度（结论级）
有来源结论有直接来源链接。 部分来源部分有来源，部分是推断。 经验判断没有直接来源，先验证再用。

机会评分卡

总分 = 各项分数 × 权重之和。A ≥ 3.5，B ≥ 3.0，其余 C。线索不打分，已排除保留原因。

缺口类型
  • 痛点缺口：主流品的集中差评没人解决。
  • 价格带缺口：两个价位之间没有供给。
  • 规格缺口：某个维度组合市场上很少。
  • 场景缺口：有人群或用法，没有专门的产品。

白地图判读

  • 供给 5 级：红海 / 有供给 / 稀少 / 空白 / 不成立（没需求或组合不合理）。
  • 需求信号 4 级：强 / 中 / 弱 / 待验证。
  • 机会格 = 供给稀少或空白 + 需求中等以上。
  • 空白但需求无证据 → 待验证，不当机会。
  • 价位分布条（低 / 中 / 高）用来发现同一组合里的价格空档。
