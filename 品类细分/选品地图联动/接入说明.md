# 开品维度图谱接入说明

状态：**已实现待验证**（2026-11-06，本地程序；未在线发布）。

## 做了什么

开品维度图谱（在售类型、分类维度、开品机会、白地图）直接接进选品地图的思维导图，不是单独入口。在导图里点对应的分类节点（例如 耗材 › 本册纸张 › **水彩纸**），下一级就是：

| 分支 | 内容 | 和地图的联动 |
|---|---|---|
| ① 市场在售商品类型 | 类型分组 → 在售类型 | 地图里的形态（C088 等，同一份记录）挂在对应的在售类型下；点形态打开原有的形态详情 |
| ② 分类维度 | 维度组 → 维度类 → 维度 → 取值 | 维度详情反查哪些在售类型用了这个取值 |
| ③ 缺口与开品机会 | A / B / C / 线索 / 已排除 | 机会详情列出对标的在售类型和地图里的相关形态 |
| ④ 白地图 | 各张白地图 | 打开整张表；格子里的类型、机会可跳回导图 |

详情都显示在原有的右侧详情面板里。地图里还没有对应形态的在售类型标“地图无形态”；还没对应到在售类型的地图形态归在“地图形态 · 未对应在售类型”。

已接入 13 个品类：针管笔、水彩本，颜料系列（水彩 / 水粉 / 丙烯 / 油画），画架系列（立式 / 桌面 / 写生 / 展示 / 儿童画架、画箱、画柜）。挂接位置见 `selection_map/dimension_links.json` 的 `attach`。

## 数据

- `selection_map/data/dimension_atlas/*.json`：开品维度图谱各品类数据，从交接包 v1.3 原样导入。这是分类标准和市场类型研究，**不是** `product_map.json` 的第二份主数据，不改动任何形态记录、覆盖或核验状态。
- `selection_map/dimension_links.json`：挂接规则和“形态编号 → 在售类型”的对应（第一个为主对应）。**均为初步对应，待人工确认。**
- `selection_map/web/dimension-data.js`：生成物，运行 `python3 selection_map/build_dimension_data.py` 生成（会校验品类、类型名、形态编号），不要手改。

## 代码

- `web/dimension.js`：挂接、导图外观、详情、白地图弹出层。
- `web/dimension.css`、`web/dimension-figs.src.js`（结构示意图）。
- `web/app.js`：`treeData()` 末尾挂接；`renderMap()` 识别维度节点；`activateDim / focusDim / writeDimDetail`；`select()` 清除维度选中。
- `web/index.html`：引入以上文件。
