# 测试 3：静态审查（本环境无法真机运行的专家）

| 专家 | 结论 |
|---|---|
| 资讯速递 aihot | 意图路由、HTML/Markdown 双输出、日报 404 回退昨日、空结果提示都有。缺“API 不可达或被网络拦截”时的兜底话术：本环境实测 aihot.virxact.com 被代理拦截（403），这时专家既不能调用，又被禁止凭记忆回答。 |
| 小企业经营团队 | 铁律、红线、4 个预设工作流、落盘路径、统一收口模板都很完整，可以直接当专家团模板。依赖宿主的 TeamCreate / SendMessage，离开 WorkBuddy 无法复现。 |
| 文爆爆（基础款） | 英文模板改编：身份指令 + 能力清单 + Success Metrics。没有交付规范，也没有追问规则；快捷问题缺少品牌信息时，输出质量全靠模型自己发挥。 |
