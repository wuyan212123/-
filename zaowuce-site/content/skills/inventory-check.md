## 适合什么时候用

刚生成完新版进销存表格，想在交付前多做一遍系统检查时。它不能代替你自己的核对，只是帮你找出容易漏看的地方。

## 准备输入

1. 本次主结果，先删除或替换掉不能外发的信息。
2. 本次更新记录。
3. 工具页面上的核对清单。

## 提示词

```prompt
你是一名进销存数据核验助手。我会提供三份材料：本次生成的进销存主结果、配套的更新记录、核对清单。

请按以下步骤工作：
1. 先列出材料中缺失的文件或字段，缺失时不要猜测，直接标为「无法核验」。
2. 按核对清单逐项检查，每项给出：检查项、结果（通过／不通过／无法核验）、依据（具体的表名、行或数值）。
3. 单独列出所有标有「待核对」的范围，并说明原因。
4. 找出数值为 0 但更新记录显示为缺失的项目。

输出格式：
- 一张核验表
- 「需要人工处理」清单
- 不确定的地方明确写「待确认」，不要给出没有依据的结论
```

## 检查 AI 的输出

- [ ] 每个「通过」都写了具体依据
- [ ] 没有出现材料中不存在的数字
- [ ] 「待核对」范围与程序完成页显示的一致
