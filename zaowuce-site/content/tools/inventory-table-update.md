## 准备三类文件

| 文件 | 是什么 | 从哪里来 |
| --- | --- | --- |
| **主表** | 上一次更新得到的进销存表格 | 上次运行得到的主结果 |
| **更新记录** | 与主表配套的过程记录，本次更新要读取它 | 上次运行时一并生成 |
| **源报表** | 本期导出的各类业务报表 | 按《准备三类文件》逐类导出 |

> [!info] 第一次使用，先用练习样表
> 下载练习样表 SAMPLE-01 走一遍完整流程，熟悉后再处理正式表格。

## 运行

1. 解压下载包，双击启动程序，浏览器会打开操作页面。
2. 依次选择主表、更新记录和源报表。
3. 点击「预检」，查看问题清单。预检不通过时，程序不会修改任何正式结果。
4. 预检通过后点击「生成」，等待完成，期间不要重复点击。
5. 分别下载主结果和更新记录，把两个文件放在同一个文件夹里。

## 看懂完成状态

| 状态 | 含义 | 接下来 |
| --- | --- | --- |
| **成功** | 所有范围都已处理 | 按核对清单抽查后即可使用 |
| **部分完成** | 部分范围被隔离，结果标有「待核对」 | 已处理的范围可以继续使用，被隔离的部分单独核对 |
| **失败** | 没有生成正式结果 | 查看原因，修正文件后重新运行 |

> [!warn] 页面显示「完成」不等于结果可以交付
> 一定要按下面的清单核对输出内容，而不是只看文件有没有生成。

## 核对结果

- [ ] 结果中的程序版本和业务基准日正确
- [ ] 状态为成功；或为部分完成，且已看过被隔离的范围
- [ ] 主结果和更新记录是两个独立文件
- [ ] 按样表核对清单抽查的汇总值一致
- [ ] 缺失的数据显示为缺失，没有被当作 0

## 下次更新要保留什么

| 本次得到 | 下次作为 |
| --- | --- |
| 主结果 | 主表 |
| 更新记录 | 更新记录 |

> [!danger] 不要丢失更新记录
> 缺少上次的更新记录，下次就无法正确更新。请把两个文件一起归档。
