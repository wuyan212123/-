# 更新记录

## 2026-10-17

- **新增** 全站快速搜索：在任何页面按 Ctrl K（Mac 上按 ⌘ K）即可搜索工具、SKILL 和文章，空白时列出最近访问的页面。
- **新增** 收藏：在工具、SKILL 和文章页面点「收藏」，常用内容会出现在首页，换一台电脑登录也在。
- **新增** 文章和工具页底部的「这篇有帮助吗」，你的反馈会直接到站主那里。
- **改进** 工具页会识别你的电脑系统，优先显示对应的安装包。
- **改进** 知识库改为三栏阅读：左侧文章列表、右侧本页目录，文末有上一篇和下一篇。

## 2026-10-16

- **新增** 造物册首版：工具目录、SKILL、知识库、搜索、成员登录与管理。
- **新增** 「进销存表格更新」页面，按准备文件、运行、核对结果、保留文件四步编写。
